# 초과배당(상증법 제41조의2)·차등배당

> **한눈에** 지분 정리 뒤 부모인 최대주주가 배당을 포기하거나 불균등 배당을 해, 자녀나 가족법인이 지분율보다 많은 배당을 받게 하는 방법입니다. 메인 구조가 아니라 지분 이전 속도를 높이는 보조수단입니다.

## 이런 업체에 맞아요
- 자녀나 가족법인으로 지분 정리를 마친 법인
- 배당가능이익이 꾸준한 법인

## 대표가 느끼는 고민
- 자녀에게 재산을 합법적으로 조금씩 넘기고 싶다

## 해결 방향
1. 배당가능이익 확인
2. 정관에 차등배당 근거 마련, 주주총회 절차 준수
3. 개인 자녀는 주주별 연 **2천만 원** 이하 분리과세 범위로 관리
4. 가족법인이 받는 초과배당은 특정법인 증여의제 과세 가능성까지 검토

세무 처리는 세무사 검토 사항입니다.

## 첫 미팅에서 이렇게 물어보세요
- "자녀분들 지분은 지금 어느 정도 있으세요?"
- "매년 배당은 하고 계세요?"

## 이렇게 말해 보세요
> "대표님, 자녀분 지분에 매년 균등하게 배당하는 것도 합법적인 재산 이전 수단이 됩니다."

⚠ 초과배당은 장기 설계가 필요해 처음부터 전면에 두지 않습니다.
