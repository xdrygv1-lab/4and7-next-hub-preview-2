# 자동작성 예시 2: 강사 원장 A (법인전환 제안)

> **한눈에** 학원 강의로 소득이 큰 개인사업자 원장님에게 법인전환을 제안한 실제 흐름을 익명으로 정리했어요. 도구가 낸 진단과 금액 가이드가 실제 제안과 어떻게 맞았는지 볼 수 있어요.

## 상황카드 (도구에 넣은 값)

| 항목 | 값 |
|---|---|
| 업종·형태 | 학원 강의, 개인사업자 |
| 매출 | 약 **4.25억** (5억 근접) |
| 순이익 | 약 **3.3억** (실경비율 22% 가정, 추정) |
| 가족 | 배우자, 자녀 2명 |
| 관계 | 기장 거래처 |
| 특이사항 | 월 생활비 약 1,200만원 / 교재·영상으로 확장 계획 / 해외주식 투자 관심 / 퇴직금 준비 없음 |

## 도구가 낸 진단

| 순위 | 컨셉 | 근거 |
|---|---|---|
| 1 | **법인전환** | 순이익 3.3억으로 높은 세율 구간, 성실신고 기준 직전 |
| 2 | 노후자금 · 퇴직금 | 개인사업자라 퇴직금 제도 없음 |
| 3 | 구조 셋팅 | 교재·영상 등 새 사업 계획 |

## 첫 미팅(AP)에서 이렇게 열었어요

> "원장님, 순이익이 3억이 넘으셔서 지금 세율이 가장 높은 구간에 계세요."

> "매출이 5억을 넘기 전이 갈림길이에요. 넘은 뒤에 바꾸면 신고 부담이 오히려 커집니다."

> "원장님은 한 달에 실제로 얼마 정도 쓰세요? 그 금액은 그대로 가져가시는 구조로 맞춰 보겠습니다."

- ✓ 상품 이야기는 하지 않고 "그릇을 바꿀 때"까지만 말했어요.
- ✓ 다음 미팅에 "법인으로 바꿨을 때 비교 자료"를 가져가기로 약속했어요.

## PC 제안서는 이렇게 짰어요 (15장)

| 순서 | 무엇을 보여주나 |
|---|---|
| 1~3 | 지금 상황 4가지, 왜 지금인지 (세율·보험료가 오르는 흐름) |
| 4, 6 | 법인으로 바꿨을 때 비교 (매출 4억~7억, **추정치 · 세무사 검토**) |
| 7 | 월 생활비 1,200만원을 그대로 가져가는 구조 (급여 + 배당) |
| 5, 8, 9, 10 | 법인의 의미: 자녀 지분으로 승계, 투자, 돈을 꺼내는 세 가지 길 |
| 11 | 꼭 지킬 것: 법인의 실체 갖추기 (교재·영상 매출, 정식 고용, 실근무 급여) |
| 12~13 | 진행 순서와 오늘 정할 것 (주소·상호·서류) |
| 14~15 | 부록: 법인을 잘 만들어도 남는 빈칸 (유고 시 현금, 퇴직금 재원) |

⚠ 비교 숫자는 매출·경비·세법에 따라 달라지는 추정치예요. 세무 처리는 세무사 검토 사항입니다.

## 제안 금액: 도구 가이드 vs 실제

| 구분 | 월 보험료 |
|---|---|
| 도구 A안 (보수적) | 150만원 |
| **실제 제안** | **200만원** |
| 도구 기준안 | 250만원 |
| 도구 B안 (적극적) | 350만원 |

> "법인을 처음 시작하는 시기라 현금흐름이 먼저예요. 월 200으로 시작하시고, 매출이 오르면 그때 늘리시면 됩니다."

## 자주 나온 반론과 대응

| 원장님 말 | 이렇게 답했어요 |
|---|---|
| "200도 부담돼요" | "150으로 시작하고 매출 보고 올리셔도 됩니다" |
| "지금 바빠서 나중에" | "설립하고 석 달 현금흐름을 보고 시작하셔도 돼요" |
| "법인만 먼저 하고 나중에" | "법인에 돈이 쌓이기 전, 혼자 버시는 지금이 유고 대비가 가장 필요한 때예요" |
| "수익률이 별로라던데" | "수익 상품이 아니라 기능 상품이에요. 비교 대상은 준비 안 된 퇴직금과 유고 상황이에요" |
| "아는 설계사가 있어요" | "법인 규정과 맞물리는 설계라 세무 설계와 같이 가야 사고가 없어요. 같이 보셔도 됩니다" |

## 최종 점검에서 짚은 것

- ⚠ 컨설팅 수수료 이야기와 보험 이야기는 **시간을 두고 따로** 했어요. (섞이면 특별이익 제공 소지)
- ⚠ 보험료 비용 처리는 단정하지 않고 "상품 정할 때 정확히 안내"로 말했어요. (세무사 검토 사항)
- ⚠ 법인이 "이름만 법인"으로 보이지 않도록 실체를 갖추는 계획을 함께 냈어요.
- ⚠ 배우자 급여는 실제 근무 기준, 자녀 지분·배당은 증여 공제 범위 안에서 설계 (세무사 검토).

## 이 예시에서 배울 점

1. **때를 잡았어요.** 매출 5억을 넘기 전이라는 "갈림길"이 가장 강한 명분이었어요.
2. **생활비부터 지켜줬어요.** 월 1,200만원을 그대로 가져가는 구조를 먼저 보여주니 걱정이 줄었어요.
3. **보험은 마지막, 작게.** 구조 설명이 끝난 뒤 빈칸을 채우는 장치로, 가이드 범위 안의 금액으로 시작했어요.

- [ ] 수수료와 보험 안내를 따로 했나요
- [ ] 재정심사로 금액을 확인했나요
- [ ] 법인 실체(매출 구조·고용·급여) 계획이 있나요
