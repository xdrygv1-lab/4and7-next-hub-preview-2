# 다점포 법인 창업 · 구조변경

> **한눈에** 여러 점포를 개인 명의로 나눠 운영하거나 새로 열 때, 하나의 법인 아래 본점과 지점으로 묶는 구조입니다. 신규 출점이면 법인 설립과 다점포 개설을 "하나의 창업 계획"으로 설계해 창업중소기업 감면을 검토합니다. 세무 처리는 세무사 검토 사항입니다.

## 이런 업체에 맞아요
- 여러 매장을 가족·직원 명의로 나눠 운영하는 곳
- 매장별 책임자가 지분을 가진 구조로, 감면 종료 시점에 재논의가 필요한 곳
- 여러 점포를 한꺼번에 새로 열 계획인 청년 창업자

## 대표가 느끼는 고민
- 명의 분산에 따른 실질과세 리스크
- 소득 합산 부담

## 해결 방향
1. 대표·주주의 기존 동종사업 이력 점검
2. 모든 점포가 인수가 아닌 신규 출점인지 확인(사업 양수는 창업 배제)
3. 법인 설립 전에 본점과 지점 전체 사업계획 확정, 설립 직후 지점 설치 일괄 결정·등기
4. 사업장별 개별 등록, 인테리어 착공 전 지점 사업자등록
5. 감면소득 구분경리, 필요 시 세법해석 사전답변 신청

⚠ 핵심은 "같은 날짜"보다 "같은 창업 계획"입니다. 1호점 영업 후 순차 출점하는 흐름은 피합니다.

| 감면 검토 포인트 | 내용 |
|---|---|
| 청년 요건 | 대표가 지분 **51%** 보유 최대주주여야 함. 지분 없으면 일반 감면률 |
| 업종 | 음료 판매 등으로 주업종이 바뀌면 감면 제외 위험 |
| 업종 추가 | 설립 후 새 업종 추가는 창업 배제 사유로 보일 수 있음 |

## 첫 미팅 질문
- "대표님이나 주주분들이 같은 업종을 운영하거나 폐업한 이력이 있으세요?"
- "열려는 점포가 모두 새로 여는 곳인가요, 기존 점포를 인수하는 곳인가요?"
- "점포를 몇 개, 언제까지 여실 계획이세요?"

## 이렇게 말해 보세요
> "대표님, 점포를 하나씩 여는 것보다 처음부터 전체 계획을 하나로 잡는 게 중요합니다."

> "자본금 규모 자체는 감면 요건과 관계없지만, 초기에 자본잠식이 표시될 수 있다는 점은 미리 알고 계시면 좋습니다."

## 자주 나오는 반론
| 반론 | 대응 |
|---|---|
| | 감면이 인정되지 않을 경우의 Plan B(정상 납부 운영)까지 함께 안내 |

## 연결되는 상품
원 자료에 연결된 보험 논리 없음.

## 꼭 확인할 것
- [ ] 청년 연령 요건 시한 안에 설립하는지
- [ ] 자녀 출자금은 기존 사전증여와 10년 합산
- [ ] 외부 자금 차입 시 이자 원천징수와 이자율
- [ ] 지방세 감면 일몰·요건, 해당 업종 인정 예규 (확인 필요)
- [ ] 사업계획서, 견적서, 이사회의사록, 지점설치등기 등 날짜 증빙
