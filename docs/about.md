# 사이트 안내

> **한눈에** 대표님을 처음 만나러 가기 전에, 무슨 말을 하고 무엇을 준비할지 도와주는 사이트입니다. 현장에서 통한 방법을 한곳에 모아서, 누구나 똑같이 꺼내 쓸 수 있게 만들었습니다.

## 이 사이트는 무엇인가요?

시험 보기 전에 보는 **"정리 노트"** 같은 곳이에요.
업체 이야기를 넣으면 이렇게 도와줘요.

| 넣는 것 | 받는 것 |
|---|---|
| 업체 숫자 (매출, 이익 등) | 이 업체에 맞는 이야깃거리(컨셉) |
| 업체 상황, 특별한 점 | 첫 만남에서 할 말(스크립트) |
| 내가 쓴 스크립트 | 점수와 고칠 점 |
| 다 만든 자료 | 마지막 점검표 |

## 왜 만들었나요?

- 처음 하는 분들은 **"가서 무슨 말을 하지?"** 가 제일 어려워요.
- 잘하는 분들의 방법이 **각자 머릿속에만** 있었어요.
- 그래서 그 방법을 꺼내 모아 **누구나 쓸 수 있게** 했어요.

## 누가 만드나요?

4사업단과 7사업단이 함께하는 **9명의 개발팀**이 만들어요.
세무사, 회계사, 노무사, 변리사, 지점장이 각자 잘하는 것을 보태요.

## 어떤 생각으로 만들었나요?

1. **쉬워야 해요.** 처음 보는 사람도 바로 쓸 수 있게.
2. **도움이 돼야 해요.** 실제 미팅에서 바로 쓸 수 있는 말과 자료로.
3. **믿을 수 있어야 해요.** 왜 그런 결과가 나왔는지 근거를 같이 보여줘요.
4. **함께 키워요.** 쓰는 사람이 보탤수록 더 좋아져요.
5. **고객 정보는 지켜요.** 이름, 회사명, 연락처는 넣지 않아요.

## 메뉴는 일곱 개예요

| 메뉴 | 들어 있는 것 |
|---|---|
| 홈 | 처음 화면 |
| 사이트 안내 | 이 사이트는 · 메뉴별 쓰는 법 · 만든 구조 · 3분 시연 · 사용 원칙 · 최근 업데이트 |
| 업체 분석 → 제안 준비 | 분석 보고서, 컨셉, AP 스크립트, 제안 준비, PPT |
| 재정심사 → 청약 | 재정심사 계산기, 청약 체크리스트, 상품 자료실 |
| 연습하기 | AP 롤플레이, 보험 MBTI |
| 공부하기 | 컨셉 사전, 첫 미팅 화법, 상품별 정리, 신입 가이드, 상품 비교, 경정기 비교 계산기, 상품 자료 받기, 물어보기 |
| 함께 만들기 | AI에게 가르치기, 보완 필요 목록 |

메뉴마다 쓰는 법은 **사이트 안내 → 메뉴별 쓰는 법**에, 순서까지 자세한 설명은 공부하기 › 신입 가이드의 **지점원 기본 가이드북**에 있어요.

## 어떻게 더 똑똑해지나요?

여러분이 자료를 보태 주면 이렇게 좋아져요.

| 보태 주는 것 | 좋아지는 것 |
|---|---|
| 내가 쓴 첫 만남 스크립트 | 스크립트가 더 자연스러워져요 |
| 제안서, PPT | 보고서와 PPT가 더 멋있어져요 |
| 미팅 녹음, 녹음 글 | 잘 되는 말투를 배워요 |
| 가입이 되고 안 된 경험 | 얼마를 제안할지 더 정확해져요 |
| 고객이 물어본 질문 | 상품별 정리가 풍부해져요 |
| 나만의 경험 이야기 | 내 말투에 맞는 스크립트가 나와요 |

보태는 곳은 **함께 만들기** 메뉴예요. 고객 이름은 꼭 지우고 보내 주세요.
