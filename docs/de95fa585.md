# AP 15단계 표준

> **한눈에** 첫 미팅(AP) 20분을 15단계로 나눈 표준 구조입니다. AP의 산출물은 계약이 아니라 **다음 약속과 소개** 두 가지이며, 상품 이야기는 한 번도 하지 않습니다.

## 핵심 원칙 5
1. **산출물은 다음 약속 + 소개.** 상품이 아니라 "나라는 전문가"를 판다.
2. **상품명은 꺼내지 않는다.** "구조가 있습니다"까지가 한계선(상품명·구조 언급 **−5점**).
3. **상대 입에서 나온 숫자만 근거.** 내가 말한 숫자는 근거가 안 된다.
4. **거절은 AP에서 이미 예고된다.** 저항은 나오기 전에 먼저 꺼내 푼다.
5. **앞에서 던진 것을 뒤에서 회수.** 3단계 사례 → 13단계, 10단계 "갈림길" → 소개요청.

⚠ 머릿속으로는 다음에 쓸 상품을 정해 두고 그 니즈를 확인하되, 입 밖으로는 꺼내지 않습니다.

## 시간 배분 (20분)

| 블록 | 단계 | 시간 | 목표 |
|---|---|---|---|
| 진입 | 1~5 | **5분** | 명분 세우고 시간 확보 |
| 전개 | 6~9 | **7분** | 객관 팩트 → 우리 회사 숫자 → 갭 |
| 전환 | 10~11 | **3분** | 저항 먼저 꺼내고 그릇 바꾸기 |
| 정보수집 | 14 F.F → 12 → 13 | **3분 30초** | 정보 받고 온도 올리기 |
| 클로징 | 15 + 소개요청 | **1분 30초** | 산출물 두 가지 |

순서보다 **각 단계를 이행했는지**가 중요합니다. 20분은 목표 시간이며, 끝까지 마치는 것이 우선입니다.

## 15단계 한 장 표

| 단계 | 목적 | 한 줄 예시 멘트 | 체크포인트 |
|---|---|---|---|
| 01 릴렉스 | 업을 아는 사람으로 첫 30초 | "지게차가 바쁘네요. 작년엔 안 그랬는데." | 날씨·교통 말고 현장에서 본 것 |
| 02 자존감·동질감 | 칭찬 + 공통점 동시에 | "저도 세법 업데이트하면서 매년 조금씩 나아지는 것 같습니다." | "대단하십니다"와 "저도 비슷합니다" 둘 다 |
| 03 본인·회사소개 | "왜 이제 와서?" 먼저 해소 | "작년부터 포지션을 바꿨습니다." | 포지션이 바뀐 명분이 섰는가 |
| 04 방문목적 | 이유를 처음부터 두 개로 | "결산도 결산이지만, 대표님 이야기를 좀 들어보려고요." | 상대 입장에서 납득되는가 |
| 05 시간확보 | 시간 동의 + 질문 예고 | "결산 20분, 컨설팅 20분. 제가 질문을 좀 드릴 겁니다." | 명시적으로 요청·동의 |
| 06 일반적 사례 | 반박 불가 객관 팩트 | "종합소득세 최고 **49.5%**, 건보료까지 더하면 거의 절반입니다." | "제 생각에는" 금지 |
| 07 구체적 사례 | 우리 회사 숫자로 내리기 | "당기순이익이 1억을 넘어 **35%** 구간에 들어오셨습니다." | 상대 회사 숫자인가 |
| 08 니즈환기 | 상대 입으로 목표·숫자 | "은퇴 후 월 생활비는 어느 정도 쓰실 것 같으세요?" | 질문 5개로 숫자 받아내기 |
| 09 문제제기 | 필요액 vs 준비액 나란히 | "15억이 필요한데 준비된 건 없습니다." | 감정 없이 산수만 |
| 10 선거절처리 | 저항 먼저 꺼내 "자격"으로 반전 | "이익이 안 나는 회사는 이런 고민 자체를 안 합니다." | 저항 전에 해소(승부처) |
| 11 대안제시 | "구조가 있다" 기대감만 | "이제 법인이라는 그릇으로 옮기실 때가 된 것 같습니다." | 상품명 0, PC 내용 미리 말하기 **−5** |
| 14 F.F | 재무·가족·목표 정보 받기 | "이게 되는지 보려면 몇 가지 여쭤봐야 합니다." | 대안 뒤에 물어 명분 부여, 기존 보험은 가입 스토리 |
| 12 일반적 예화 | 준비 없는 결말 그리기 | "끝은 둘 중 하나로 옵니다." | 갑자기 오는 경우 / 천천히 오는 경우 |
| 13 구체적 예화 | "그게 나였다면" | "불편하시겠지만 잠깐만 대입해보겠습니다." | 3단계 사례 회수 |
| 15 다음 약속 | 일자+시각+소요시간+가져올 것 | "시뮬레이션 돌려서 가져오겠습니다. 목요일 오후 2시, 한 시간 잡아주세요." | "연락드리겠습니다"는 **0점** |
| ☆ 소개요청 | 대상·인원 특정 | "비슷한 고민 하시는 분 딱 두 분만 소개해주세요." | 10단계 논리의 결론으로 |

## 단계별 분기 포인트

| 단계 | 분기 | 내용 |
|---|---|---|
| 03 | 기장거래처 | "작년부터 포지션을 바꿨습니다" (막을 의심: 왜 갑자기?) |
| 03 | 소개받은 자리 | "OO 대표님이 대표님을 지목하셨습니다" (왜 나를?) |
| 03 | 완전 초면 | "기장 영업하러 온 게 아닙니다" (기장 뺏으러?) |
| 06~07 | 개인사업자·이익 발생 | 소득세율 + 건보료 → 법인이라는 그릇 |
| 06~07 | 법인 대표 | 비상장주식 평가액 → 상속세 → 지금이 가장 싼 시점 |
| 06~07 | 자산 많고 소득 적음 | 부동산 비중 → 납부재원 부족 → 현금 만드는 구조 |

**08 니즈환기 질문 5개:** 원동력 → 언제까지 → 은퇴 후 모습 → 월 생활비 → 계산 제시(월 **600만원 × 12 × 약 20년 = 약 14~15억**, "준비하고 계신 게 있습니까?")

## 저항 대응

| 시점 | 저항 멘트 | 이렇게 대응 |
|---|---|---|
| 6~7단계 | "그런 얘기는 많이 들어봤어요." | 3단계에서 외부 컨설팅 이야기를 먼저 깔고, "오늘은 대표님 회사 숫자로만 말씀드리겠습니다"로 7단계로 내려가기 |
| 9~10단계 | "그거 결국 보험 얘기 아니에요?" | 부정하지 말고 "보험으로 활용할 수도 있지만 오늘 제안드리는 건 아니고, 전체 구조를 보고 필요하면 제안드리겠습니다" |
| 11단계 직후 | "지금은 좀 그래요. 나중에 하죠." | "갈림길" 논리 재사용: "가만히 계시는 게 가장 비싼 선택입니다", "판단은 빠를수록 선택지가 많습니다" |
| 약속 잡을 때 | "생각해보고 연락드릴게요." | 확정형으로 먼저 제시, 이지선다(화요일 오후 / 목요일 오전) |

## 채점표 요약
- 총 **100점** = 이행 **70**(01~14 × 5) + 다음 약속 **10** + 소개요청 **5** + 종합 재량 **15** − 감점
- 다음 약속: 일자+시각+소요시간 10 / 일자+시각 8 / 일자만 5 / 주 단위 3 / 미확정 0
- 소개요청: 대상+인원 특정 5 / 하나만 3 / 막연 1 / 없음 0
- 종합 재량 기준: "내가 이 대표라면 다음 미팅에 응하겠는가?"
- 감점: 상품명·구조 **−5** / 상황카드 미제출·불일치 **−5** / 확정 수익 표현 **−3** / 20분 초과 1분당 **−2** / PC 내용 미리 말하기 **−5**

## 상황카드 (생성기 입력)

| 항목 | 내용 |
|---|---|
| 상대 정보 | 업종·업력, 법인/개인, 매출, 직원 수, 대표 연령, 가족 |
| 나와의 관계 | 기장거래처(년차) / 소개 / 초면 |
| 알고 있는 정보 3가지 | 추측이 아니라 실제로 파악한 것 |
| AP 목표 | 확인할 니즈 / PC 제안 방향 |
| 예상 저항 | 어디서 막아설지 |

## 연습 태도
- 머릿속 AP는 완벽해도 입으로 하면 대부분 **5분**에서 막힙니다. 소리 내어 연습하세요.
- RP를 영상으로 찍고 스스로 피드백하세요.

## 꼭 확인할 것
- [ ] 상품명·환급률·구조를 한 번도 말하지 않았다
- [ ] 상대가 자기 입으로 목표와 숫자를 말했다
- [ ] 예상 저항을 나오기 전에 먼저 꺼내 풀었다
- [ ] 다음 약속을 일자+시각+소요시간+가져올 것까지 확정했다
- [ ] 소개요청에서 대상과 인원을 특정했다
