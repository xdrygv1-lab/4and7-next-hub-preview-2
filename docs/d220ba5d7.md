## 숫자를 받아내는 질문 세트
1. "이 사업을 열심히 하시는 원동력이 어떤 거세요?"
2. "사업은 언제까지 하실 생각이세요?"
3. "그 이후의 모습을 생각해 보신 적 있으세요?"
4. "은퇴 이후 월 생활비는 어느 정도일까요?" → "월 600이면 되실까요?"
5. (계산 후) "혹시 준비하고 계신 게 있습니까?"

F.F 전환: "이게 되는지 보려면 몇 가지 여쭤봐야 합니다." (가족·자녀, 생활비, 기존 보험 가입 스토리, 사업장 외 재산, 지출 계획)

## 반론처리 공식
- **인정 → 의미 반전:** "맞습니다. 다만 잘못하고 계시다는 게 아니라 대비할 수 있는 갈림길에 서 계신 겁니다. 이익이 안 나는 회사는 이런 고민 자체를 안 합니다."
- **선거절:** 고객이 꺼내기 전에 내가 먼저 꺼내 해결합니다. 거절은 정형화되어 있습니다.
- **이성에 공감, 감정에 확신:** "신중하셔야 합니다. 다만 이 리스크를 막지 못했을 때의 대가가 훨씬 크기 때문에 강하게 말씀드립니다."

| "지금은 좀 그래요." | "판단은 빠를수록 선택지가 많습니다." 매년 늘어나는 숫자 제시 |
| "생각해보고 연락드릴게요." | "시뮬레이션 돌려서 가져오겠습니다. 목요일 오후 2시, 한 시간 잡아주세요." |
| "법인이 내면 법인 돈 아니에요?" | "맞습니다. 법인에 들어온 돈을 어떻게 쓸지까지 구조를 정리해 드립니다." 절차 설명은 하지 않음, 세무 처리는 세무사 검토 사항 |
| "가업상속공제 받으면 세금 안 나온다던데" | 세무사 검토 사항으로 안내 |
| "법인 하면 세금 두 번 내잖아" | 분리 운영 단점 먼저 인정 → 퇴직금·세율 구간·자녀 증여 3가지 → 숫자는 다음 미팅에 |
| "환급률이 100%가 안 되잖아" | 보장 목적 상품임을 설명, 세무 처리는 세무사 검토 사항 |
| "납입 여력이 안 돼요" | 계약대출, 감액완납(**5년**)·종신전환(**7년**) |
| "10년 할 수 있을지 모르겠다" | 중간 정지 옵션(감액완납·종신전환) |
| 체증형 "보험료 부담" | 일반형 대비 **8.7%** 저렴, 7년 후 환급률 **100%** |
| 체증형 "중간에 해지하면?" | 3년 미만 **0%**, 7년 유지 전제 상품임을 먼저 고지 |
| 체증형 "유동성이 묶인다" | 7년 후 적립형 전환·추가납입 인출(연 **12회**) |
| "다 넣으면 나는 뭐 먹고 사냐" | 규모 축소 수용(**60%**만 해도 효과), 비재무적 요소 존중 |
| 사근복 "직접 하면 되지 않나" | "직접 하실 수 있어요. 처음 1~2년은 함께 관리하시는 게" + 전수조사 리스크 |
| 외부 업체 제안을 들고 올 때 | "다 사기"로 일축하지 말고 리스크·사후관리까지 보는 전문가로 응답 |

## 휴먼터치 팁
- **칭찬과 공통점을 같이.** 하나만 있으면 아부이거나 건방집니다.
- **기존 보험은 "어떻게 가입하셨는지"**를 물으세요.
- **가족 이야기로 감성 터치.** 사람은 죽음에 낙관적이라 숫자만으로는 안 움직입니다.
- **핵심 숫자 뒤 3초 침묵.** 확신은 눈빛에 드러납니다.
- **도장 후 첫 출금 전까지 케어.** 대표가 가장 불안해하는 기간입니다.
