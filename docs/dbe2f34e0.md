# 특정법인 증여의제(상증법 제45조의5) 관리

> **한눈에** 지배주주 일가가 **30%** 이상 가진 법인에 특수관계인이 무상제공, 채무면제, 저가양도, 초과배당 등으로 이익을 주면 그 이익을 주주의 증여로 보는 규정입니다. 주주별 **1억 원** 이상일 때만 과세합니다. 가족법인 설계의 규제이자 활용 한도입니다.

## 이런 업체에 맞아요
- 가족법인을 만들어 부모 재산을 옮기려는 자산가
- 부모가 가족법인에 대여, 채무면제, 현물출자 등을 계획하는 경우

## 대표가 느끼는 고민
- 가족법인으로 재산을 옮기면 세금이 어떻게 되는지 모른다
- 여러 거래가 겹치면 한도를 넘을까 걱정된다

## 해결 방향
1. 거래 유형 확인 (아래 표)
2. 법인 이익 × 주주 지분율로 주주별 이익 계산
3. 거래일부터 **1년** 이내 동일 거래는 이익별로 합산해 1억 원 기준 판단
4. 같은 해 여러 거래가 겹치면 합산 여부를 사전 계산
5. 매년 다시 검토한다는 전제로 설명

| 해당 거래 유형 |
|---|
| 재산·용역 무상 제공 (초과배당 포함) |
| 현저히 낮은 대가로 양도·제공 |
| 현저히 높은 대가로 양수·제공받기 |
| 법인 채무 면제·인수·변제 |
| 시가보다 낮은 현물출자 |
| 불균등 감자 등 자본거래를 통한 이익 분여 (개정 신설) |

세무 처리는 세무사 검토 사항입니다.

## 첫 미팅에서 이렇게 물어보세요
- "가족법인 주주는 어떻게 구성되어 있나요?"
- "올해 부모님과 가족법인 사이에 대여나 채무면제 계획이 있으세요?"

## 이렇게 말해 보세요
> "대표님, 가족법인은 잘 쓰면 강력하지만, 특정법인 규제를 어기면 오히려 증여세가 나옵니다. 거래를 시가와 정상 대가로 하는 구조 설계가 전부입니다."

- [ ] 채무면제, 초과배당, 무상대여가 같은 해 겹칠 때 합산 여부 (확인 필요)
