# 차명주식(명의신탁) 환원

> **한눈에** 설립 당시 발기인 요건 등으로 다른 사람 이름에 둔 주식을 실제 주인에게 돌리는 작업입니다. 해지, 양수도, 증여, 법인 취득, 제3자 경유 중 세금과 리스크를 비교해 고릅니다. 오래된 법인이나 주주명부에 친인척·직원이 있는 법인에 씁니다.

## 이런 업체에 맞아요
- 발기인 수 요건이 있던 시절(2001년 이전 등) 설립된 법인
- 건설업 자본금 요건 등으로 타인 명의를 빌린 법인
- 주주명부에 친인척·직원 이름이 있는 법인

## 대표가 느끼는 고민
- 명의자가 주식을 마음대로 팔거나 상속이 개시될까 걱정된다
- 내 주식이라는 걸 입증하기 어렵다
- 명의신탁 증여의제 세금은 실제 소유자가 내야 한다

## 해결 방향
1. 주식 이동 이력 파악 (설립, 증자, 감자, 양도)과 각 시점 주가 확인
2. 명의자 협조 가능성과 특수관계 확인
3. 입증 자료 수집 (신탁 당시 금융기록, 실질주주의 경영 행사 증빙 등)
4. 방법별 세금 비교 후 선택
5. 환원이 어려우면 양도제한·종류주식 전환, 신탁·해지약정서, 주권 보관 등으로 대비

| 방법 | 특징 |
|---|---|
| 명의신탁 해지 | 입증되면 세부담이 적은 편, 주주권 입증 필요 |
| 시가 양수도 | 개인 재원 필요, 양도세와 자금 흐름 입증 |
| 증여 | 현금 불필요, 10년 합산 |
| 법인 취득 | 법인 재원, 추가 증여의제 검토 |
| 제3자 경유 | 새로운 명의신탁·증여의제 위험 |

세무 처리는 세무사 검토 사항입니다.
