> ⚠️ 표시는 수치·요건이 해마다 바뀌거나 확인이 필요한 항목입니다. 사이트 반영 전에 최신 법령·공고로 확인합니다.

## 0. 한 줄 요약

**"지원금·리스크 무료 진단"으로 문을 열고 → 사근복·임원 보상 규정으로 신뢰를 쌓고 → 재원 마련(경정기 등)으로 PC를 연결한다.**

노무사는 대표에게 "돈을 받아오는 사람" 또는 "사고를 막아주는 사람"으로 들어가기 쉽습니다. 세무사·회계사보다 진입 장벽이 낮다는 점이 노무 분야의 강점입니다.

## 1. 노무 컨셉 사전 (후킹 포인트 중심)

각 컨셉은 **누구에게 / 후킹 질문 / 우리가 주는 것 / PC 연결**로 정리했습니다. 후킹 질문은 AP에서 컨셉을 먼저 꺼내지 않고 니즈를 끌어내는 데 씁니다.

### 1-1. 고용지원금 무료 진단 (진입용 미끼)

| 항목 | 내용 |
|---|---|
| 대상 | 직원 5~100인, 최근 1년 안에 채용했거나 채용 계획이 있는 기업 |
| 후킹 질문 | "작년에 새로 뽑으신 직원 중에 청년이나 경력단절자가 있으셨나요? 받으실 수 있었던 지원금을 놓치신 경우가 꽤 많습니다." |
| 우리가 주는 것 | 4대보험 가입자 명부 기준으로 받을 수 있는 지원금 목록과 예상 금액 |
| 주요 지원금 ⚠️ | 청년일자리도약장려금, 고용촉진장려금, 출산·육아기 고용안정장려금, 워라밸일자리장려금(근로시간 단축), 두루누리 사회보험료 지원 등. **해마다 공고 기준으로 갱신** |
| PC 연결 | 진단 결과를 설명하는 2차 미팅이 자연스럽게 생김 → 1-4 임원 보상, 1-2 사근복으로 확장 |

### 1-2. 사내근로복지기금 (사근복)

| 항목 | 내용 |
|---|---|
| 대상 | 이익이 꾸준히 나고, 성과급·복지비 지출이 큰 중소·중견 법인 |
| 후킹 질문 | "직원분들 성과급 주실 때 4대보험이랑 세금 떼고 나면 실제로 받는 금액이 아깝다는 생각 안 드세요?" |
| 핵심 구조 | 법인 출연금은 손금 산입, 기금이 근로자에게 주는 복지 금품은 근로소득 과세 대상에서 빠짐 → 회사와 직원 모두 부담이 줄어듦 ⚠️(비과세 범위·요건 확인) |
| 근거 | 근로복지기본법(사내근로복지기금), 법인세법 손금 규정 |
| 설립 흐름 | 노사협의회 의결 → 설립준비위원회 → 정관 작성 → 고용노동부 설립 인가 → 법인 설립 등기 → 출연 |
| 주의 | 출연 기준(세전 순이익 대비 비율), 기본재산 사용 한도, 대표·임원 수혜 제한 ⚠️ 확인 필요 |
| 차별 포인트 | "설립만 해주고 끝"이 아니라 **연간 출연 계획 + 운용 + 사업 집행**까지 사후관리 → 해마다 방문할 명분 생김 |
| PC 연결 | 기금 운용 방식(금융상품 운용 범위 ⚠️ 확인), 대표 본인 보상은 1-4로 별도 설계 |

### 1-3. 정책자금 · 보증

| 항목 | 내용 |
|---|---|
| 대상 | 설비 투자, 운전자금이 필요한 제조·기술 기업, 업력 3~7년 |
| 후킹 질문 | "내년에 설비나 인력 늘리실 계획 있으세요? 금리 차이만 계산해도 꽤 큰 금액입니다." |
| 주요 기관 | 중소벤처기업진흥공단(중진공) 정책자금, 신용보증기금, 기술보증기금, 지역 신용보증재단 |
| 노무사 역할 | 고용 유지·창출 실적, 4대보험 체납 여부, 근로조건 적법성 → **정책자금 심사에서 노무 리스크를 미리 정리**해 줌 |
| 협업 | 기술보증·벤처인증은 변리사, 재무 요건은 회계사와 같이 진행 |
| PC 연결 | 자금 조달 이후 "늘어난 이익을 어떻게 지키고 남길 것인가" → 사근복, 임원 보상 |

### 1-4. 임원 보수 · 퇴직금 규정 정비 ★ (PC와 가장 바로 연결됨)

| 항목 | 내용 |
|---|---|
| 대상 | 대표가 급여를 적게 받고 이익을 법인에 쌓아둔 기업, 승계를 생각하는 50~60대 대표 |
| 후킹 질문 | "대표님 퇴직금은 회사 규정에 어떻게 되어 있으세요? 나중에 받으실 때 얼마까지 비용으로 인정되는지 확인해 보신 적 있으세요?" |
| 우리가 주는 것 | 정관·임원퇴직금지급규정·임원보수규정 진단과 정비안 |
| 핵심 포인트 ⚠️ | 정관(또는 정관이 위임한 규정)에 근거가 없으면 임원 퇴직금이 손금 불산입될 위험. 퇴직소득 과세 한도 배수도 함께 설명 (법인세법 시행령·소득세법 퇴직소득 한도 확인) |
| PC 연결 | 규정이 정비되면 "그 퇴직금 재원을 어떻게 마련할 것인가" → **경영인정기보험**, 승계·상속(회계사 파트) |

### 1-5. 노무 리스크 진단 (방어형)

| 리스크 | 후킹 질문 | 흔한 문제 |
|---|---|---|
| 포괄임금 · 연장근로 | "야근 수당은 따로 주세요, 급여에 포함해서 주세요?" | 포괄임금 무효 판단 → 미지급 수당 소급 청구 |
| 주52시간 | "바쁜 시즌에 주말 근무가 많으세요?" | 근로시간 위반, 유연근무제 미도입 |
| 퇴직금 · 퇴직연금 | "퇴직금은 DB인가요, DC인가요? 적립은 다 되어 있나요?" | 미적립·과소적립, 퇴사자 분쟁 |
| 취업규칙 | "취업규칙 마지막으로 고치신 게 언제세요?" | 10인 이상 신고 의무, 불이익 변경 동의 누락 |
| 중대재해처벌법 ⚠️ | "안전보건 담당자는 정해져 있나요?" | 5인 이상 50인 미만도 적용(2024.1~), 안전보건관리체계 미구축 |
| 근로계약서 · 4대보험 | "일용직이나 프리랜서로 쓰시는 분이 있으세요?" | 위장 프리랜서, 4대보험 소급 부과 |

**PC 연결:** 리스크 진단 보고서 → 노무 자문 계약(고정 방문) → 관계가 깊어지면 1-2, 1-4로 확장.

## 2. 노무사용 AP 흐름 (초안)

> 원칙: AP에서는 **PC 컨셉(보험·상품)을 먼저 꺼내지 않는다.** 질문으로 대표 스스로 문제를 말하게 한다.

| 단계 | 목표 | 핵심 질문·멘트 예시 | 하지 말아야 할 말 |
|---|---|---|---|
| 1. 라포 | 경계 풀기 | "업력이 ○년이시던데, 처음 시작하실 때 몇 분이셨어요?" | 바로 명함 내밀며 상품·서비스 설명 |
| 2. 회사 현황 | 인원·조직 파악 | "지금 직원은 몇 분이고, 내년에 더 뽑으실 계획 있으세요?" | "직원 많으시네요, 노무 문제 많으시죠?" (단정) |
| 3. 인사 고민 | 불편한 점 꺼내기 | "직원 관리하시면서 제일 골치 아픈 게 뭐세요?" | 문제를 먼저 지적하기 |
| 4. 돈 이야기 (가볍게) | 지원금·비용 관심 확인 | "인건비 부담은 어느 정도 느끼세요?" | 금액을 장담하기 ("무조건 ○천만 원 받습니다") |
| 5. 대표 본인 | 대표 보상·은퇴 관심 확인 | "대표님은 몇 살까지 일하실 생각이세요? 승계는 생각해 보셨어요?" | 보험·상속세 이야기를 먼저 꺼내기 |
| 6. 무료 진단 제안 | 2차 미팅 명분 만들기 | "4대보험 명부만 주시면 받으실 수 있는 지원금을 정리해 드릴게요." | 그 자리에서 계약 요구 |
| 7. 자료 요청 | PC 준비 | 4대보험 가입자 명부, 임금대장, 취업규칙, 정관, 임원 규정 | 필요 없는 자료까지 한꺼번에 요구 |
| 8. 마무리 | 다음 일정 확정 | "다음 주 ○요일에 결과 들고 다시 찾아뵐게요." | 일정 없이 "연락드리겠습니다" |

### AP 녹음 이후 체크리스트
- [ ] 상시 근로자 수 / 내년 채용 계획
- [ ] 대표가 직접 말한 고민
- [ ] 지원금 대상 가능성 (청년·고령·경력단절·육아휴직자)
- [ ] 사근복 적합도 (이익 규모, 성과급 지급 여부)
- [ ] 임원 퇴직금 규정 유무
- [ ] 대표 나이·승계 관심도 → 회계사·세무사 연결 필요 여부
- [ ] 다음 PC 추천 컨셉 1순위 / 2순위

## 3. 허브 사이트 반영 요청

### 3-1. 기업분석 입력 항목 추가 (노무 관점)
- 상시 근로자 수, 최근 3년 인원 변화 (늘었는지 줄었는지)
- 청년(15~34세) · 고령자 비율
- 퇴직연금 유형 (DB / DC / 미가입)
- 취업규칙 신고 여부, 노사협의회 설치 여부 (30인 이상 의무)
- 임원 퇴직금 규정 유무
- 사근복 설립 여부

### 3-2. 자동 산출되면 좋을 것
- **지원금 적합도 점수**: 입력값 기준으로 받을 수 있을 것 같은 지원금 목록 (단정하지 않고 "가능성" 표시)
- **사근복 적합도**: 세전 이익과 인원 기준으로 연간 출연 가능 범위와 절감 효과 예시
- **노무 리스크 신호등**: 위 1-5 항목을 🟢🟡🔴로 표시
- **노무사용 AP 스크립트**: 2번 흐름에 업체 정보를 넣어 생성

### 3-3. 데이터 갱신
- 고용지원금은 **매년 1월 고용노동부 공고 기준으로 업데이트** (담당: 노무사)

## 5. 다른 분야와 협업 지점

| 연결 | 상대 | 내용 |
|---|---|---|
| 임원 퇴직금 → 재원 마련 | 지점장 | 경영인정기보험 설계, 재정심사 |
| 승계 · 상속 | 회계사 | 대표 퇴직금 지급과 주식 가치의 관계 |
| 기술 · 정책자금 | 변리사 | 기술보증, 벤처인증, 직무발명 보상 규정 (노무 규정과 같이 정비) |
| AP 스크립트 | 지점장 | 노무사용 흐름을 공통 AP 틀에 맞추기 |
