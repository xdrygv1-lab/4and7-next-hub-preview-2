# 컨셉 체크 예시: 제조업 대표님

> **한눈에** AP 연습 녹음을 분석해 신호를 뽑고, 컨셉을 진단하고, 15단계 채점과 PC 준비안까지 만든 예시입니다. 결과는 1순위 **법인전환**, 채점 **91점**, PC는 금요일로 확정됐습니다.


## 진단 결과
- **1순위 법인전환**, 2순위 노후·퇴직금, 3순위 상속세 재원
- 핵심 근거: 법인을 "생각은 해봤다" / 노후자금 **15억** 필요, 준비 없음 / 개인사업자라 퇴직금 없고 공장이 개인 명의
- 다음 행동: 금요일 PC에서 "법인전환 세금 비교 + 은퇴자금 15억 준비 구조" 제시

## 대표 발언에서 뽑은 신호

| 신호 | 연결 컨셉 |
|---|---|
| 매출 증가, 현장 바쁨, 확장 의지 | 법인전환 |
| 당기순이익 약 **1억** | 법인전환(35% 구간) |
| 은퇴 60~65세, 은퇴 후 여행·자녀 결혼 | 노후, 자녀 증여 |
| 은퇴 후 월 **600만~1,000만원** [보정] | 노후 필요자금 근거 |
| 노후자금 준비 없음 | 노후·퇴직금 |
| 법인 검토 경험 + "법인세·소득세 둘 다 내야 하잖아" | 법인전환(반론 대비) |
| 자녀 교육비·용돈 월 **1,500만원** [보정] | 필요자금 상향 |
| 공장 자가(개인 명의), 시골 토지 | 법인전환, 상속재원 |
| 기존 보험 암·실비만 | 보장 공백 |
| 법인 유리 여부 문의 이력, 자녀 2천만원씩 증여 | 법인전환, 가족 구조 |

## 컨셉별 정리

| 컨셉 | 근거 | 아직 모르는 것 | PC 확인 질문 |
|---|---|---|---|
| 법인전환 | 순이익 1억, 확장 의지, 공장 개인 명의, 증여 이력 | 정확한 매출, 공장·토지 장부가·시가, 부채 | "공장 건물과 땅은 언제 얼마에 취득하셨어요?" |
| 노후·퇴직금 | 65세, 월 600만원, 20년 → 약 **14~15억**, 준비 없음 | 국민연금·저축, 배우자 소득 | "월 600만원은 사모님 생활비까지 포함이세요?" |
| 상속세 재원 | 사업 자산이 그대로 상속재산, 사망보장 없음 | 총자산, 부채, 자녀 연령 | 법인전환 설계 안에 "유고 대비"로 녹임 |

PC 상품 후보(고객에게 말하지 않음): 퇴직금 재원으로 경영인정기 또는 원금형 종신. 50세라 경정기 환급률이 40대보다 낮아 둘을 비교. 세무 처리는 세무사 검토 사항.

## PC 준비안
> "지난번에 65세에 은퇴하시고 월 600만원은 쓰고 싶다고 하셨습니다. 그런데 개인사업자는 퇴직금이 없다고 말씀드렸죠. 그 해결 방안을 갖고 왔습니다."

- 준비 자료: 개인 유지 vs 법인 전환 세금 비교 / 대표 급여·퇴직금 설계안(정관 규정 포함) / 은퇴자금 15억 준비 구조 / 공장·토지 처리 방안(현물출자 요건 확인 필요)
- 상품 비교: 50세 남 기준 경정기 vs 원금형 종신(시뮬레이터)
- 협업: 법인 설립·정관, 필요 시 노무사(직원 5명 처우 승계)
- A/B안: "A안 법인 전환 + 퇴직금 플랜, B안 전환은 내년 + 퇴직금 플랜 먼저, 어느 쪽이 일정에 맞으세요?"
