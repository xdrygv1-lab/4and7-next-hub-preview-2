# 특허·기업부설연구소·벤처인증 (밸류업 패키지)

> **한눈에** 특허, 기업부설연구소(또는 연구전담부서), 벤처기업 확인 순서로 "법인 스펙"을 쌓는 변리사 주도 밸류업 구조입니다. 감면, 취득세, 보증한도, 정책자금에서 우대를 받습니다. 업력이 짧은 법인이나 사업용 부동산 매입을 앞둔 법인에 씁니다.

## 이런 업체에 맞아요
- 창업 **3년** 이내 법인 (창업벤처 감면 요건)
- 업력 **7년** 이내 법인 (사업화자금 시기)
- 사업용 부동산 매입 예정 법인, 특히 수도권 과밀억제권역
- 경쟁사가 따라 하기 어려운 기술이나 시스템이 있는 곳

## 대표가 느끼는 고민
- 부동산 취득세 부담이 크다
- 보증 한도와 정책자금이 부족하다

## 해결 방향
1. 특허 출원으로 기술 혁신성 입증
2. 공간과 인적 요건을 갖춰 연구소 또는 연구전담부서 설립
3. 벤처 확인
4. 인증 후 세제 효과를 장부와 맞춰 검증

| 벤처 확인 효과 | 내용 |
|---|---|
| 창업벤처 감면 | 창업 3년 이내 확인 시 법인세·소득세 **50%** 감면 (5년간) |
| 부동산 | 취득세 감면, 과밀억제권역 중과 면제 (요건·지역별 상이) |
| 금융 | 보증한도 확대, 보증료율 감면, 정책자금 우대 |
| 인력 | 연구전담요원 요건 완화, 스톡옵션 한도 확대 |

세무 처리는 세무사 검토 사항입니다.

## 첫 미팅에서 이렇게 물어보세요
- "사업용 건물이나 부지 매입 계획 있으세요? 어느 지역이세요?"
- "회사 업력이 몇 년 차세요? 투자나 매각 생각도 있으세요?"
- "기술이나 시스템 중에 경쟁사가 따라 하면 곤란한 게 있으세요?"

## 이렇게 말해 보세요
> "대표님, 벤처 인증을 3년 안에 받아 두지 않을 이유가 없습니다."

> "단순 숙박업은 감면이 어렵지만, 소프트웨어 공급 매출을 만들면 감면과 벤처 인증이 가능할 수 있습니다. 이를 위해 특허와 연구소가 필수입니다."

## 자주 나오는 반론
| 반론 | 대응 |
|---|---|
| 50% 감면이면 엄청 크죠? | 최저한세가 걸려 생각보다 크지 않을 수 있습니다. |
| 매출이 큰데 벤처 되나요? | 매출이 너무 많으면 인증이 나오지 않는 경우도 있습니다. |

## 연결되는 상품
PC 단계에서만: 밸류업으로 잉여금·주식가치가 오르면 퇴직금 재원·상속 재원이 필요하다는 논리로 연결.

## 꼭 확인할 것
- [ ] 연구노트를 대충 만들면 단순 개선으로 볼 수 있음
- [ ] 기존 동종사업 확장은 창업으로 인정되지 않음
- [ ] 지역별 취득세 감면율 차이 (확인 필요)
- [ ] 연구소 인적 요건 (학위·자격·경력)
- [ ] 변리사와 세무사(재무요건·세제효과 검증) 역할 분담
