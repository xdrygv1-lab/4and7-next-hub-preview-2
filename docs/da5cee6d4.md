# 외부감사·횡령배임·회생파산 (접근명분용)

> **한눈에** 컨셉이라기보다 가결산·결산 미팅에 들어가는 **명분**입니다. 외부감사 대상에 가까워진 법인에 "외감 대상인지 미리 체크해 드리겠습니다"로 자리를 만듭니다. 횡령·배임과 회생·파산은 원 자료가 얇아 경고 화법 정도로만 씁니다. (확인 필요)

## 이런 업체에 맞아요
- 자산·매출·부채·직원 수가 외부감사 기준에 가까워진 법인
- 대표 개인과 법인 돈이 섞여 있고, 큰돈을 대표가 직접 받는 구조가 있는 법인

## 외부감사, 이것만 알면 돼요
| 항목 | 내용 |
|---|---|
| 감사인 선임기한 | 처음 감사받는 해: 사업연도 시작 후 4개월 이내(12월 결산이면 4/30까지) |
| | 처음이 아닌 해: 사업연도 시작 후 45일 이내(12월 결산이면 2/14까지) |
| 늦으면 | 감사인 지정 같은 조치, 고발 시 벌금·징역 같은 형사조치 가능 |
| 계약 후 | 2주 안에 증권선물위원회에 선임 보고 |

대상 기준과 기한은 해마다 바뀔 수 있어 회계사 확인이 필요합니다. (확인 필요)

## 첫 미팅에서 이렇게 물어보세요
- "올해 자산이나 매출이 작년보다 많이 늘었나요? 외부감사 대상인지 미리 같이 보시죠."
- "회사 돈이 대표님 개인 통장으로 바로 들어오는 경우가 있나요?"

## 이렇게 말해 보세요
- "외부감사 대상이 되면 선임기한을 놓치는 것만으로 문제가 됩니다. 가결산 때 기준에 닿는지 먼저 체크해 드리겠습니다."
- "회사 돈을 대표님이 받는 길은 급여·배당·퇴직금처럼 정해진 길로만 가셔야 나중에 횡령·배임 이야기가 안 나옵니다."

## 연결되는 컨셉
- 정해진 인출 길 만들기: 임원 급여·퇴직금 · 유고 대비
- 쌓인 돈 정리: 가지급금 해소

## 꼭 확인할 것
- 외부감사 기준 수치와 기한은 회계사 확인 (확인 필요)
- 횡령·배임, 회생·파산은 원 자료가 없어 사례로 단정하지 않음
