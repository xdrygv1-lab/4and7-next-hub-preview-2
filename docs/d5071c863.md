# 사근복, 노무사가 실행하는 법

> **한눈에** 지점원이 연결한 업체를 노무사가 이어받아 **사전 진단 → 제안(PC) → 설립 → 해마다 사후관리**까지 끌고 가는 실행 묶음입니다. 첫 미팅(AP) 흐름은에 있고, 여기서는 그 이후를 다룹니다.
>
> 2026-11-04 · 상태: 초안 (`[노무사 입력]` 표시는 노무사님이 직접 채울 부분)

---

## 전체 흐름과 기간

| 단계 | 할 일 | 기간 (대략) | 산출물 |
|---|---|---|---|
| 0. 인계 | 지점원 동행 요청 확인, 자료 수령 | 미팅 전 | 동행 요청서 |
| 1. AP | 첫 미팅, 니즈 확인, 자료 요청 | 1회 | 다음 약속 |
| 2. 사전 진단 | 취업규칙·복지·인원·재무 점검 | 1주 | 진단표 (1장) |
| 3. PC | 설계안과 숫자 제안 | 1회 | 제안서 (2장) |
| 4. 계약 | 설립 용역 + 사후관리 계약 | | 용역계약서 |
| 5. 설립 | 합의 → 준비위 → 인가 → 등기 → 사업자등록 → 출연 | 4~8주 | 설립 때 정할 것 (3장) |
| 6. 사후관리 | 연간 보고·회의·등기·사업 집행 | 매년 | 연간 캘린더 (4장) |

## 1. 사전 진단표 (PC 전에 반드시)

PC에서 틀린 제안을 하지 않기 위한 점검입니다. 🔴가 하나라도 있으면 설계를 바꾸거나 보류합니다.

| # | 점검 항목 | 확인 자료 | 판단 |
|---|---|---|---|
| 1 | 대표 포함 **노사 각 3명** 구성 가능 (협의회 2 + 감사 1, 감사 겸임 불가) | 근로자 명부 | 불가면 🔴 → 공동기금 검토 |
| 2 | 노사협의회 유무 (30인 이상은 설치 의무) | 협의회 규정·회의록 | 없으면 사업주 결정으로 설립. 30인 이상 미설치는 먼저 정비 |
| 3 | 근로자위원 선출 방식 (과반수 노조가 있으면 노조가 선출) | 노조 현황 | |
| 4 | **취업규칙·단체협약·내부규정에 이미 있는 복지** | 취업규칙, 단협, 복지 규정 | 이 항목은 기금 사업 불가. 옮기려면 노사 합의로 규정부터 변경 |
| 5 | 최근 1~2년 안에 **줄었거나 없어진 복지**가 있는지 | 복리후생비 원장 추이 | 기금 설립과 맞물려 감축하면 🔴 형사처벌 |
| 6 | 대표가 원하는 것이 **상여·성과급 대체**인지 | 대표 면담 | 그렇다면 🔴 설계 불가, 새 복지로 방향 전환 |
| 7 | 대표·임원이 수혜를 기대하는지 | 대표 면담 | 기대하면 🔴 처음에 정리 |
| 8 | 세전순이익 추이와 현금 여력 (출연금 회수 불가) | 3개년 재무제표 | 손실·현금 부족이면 출연 규모 축소 또는 보류 |
| 9 | 중소기업 해당 여부 (그해 출연금 80% 사용) | 중소기업확인서 | |
| 10 | 협력업체·파견 근로자 유무 | 도급·파견 계약 | 있으면 사용 한도 확대(최대 90%), 공단 지원금 |
| 11 | 자기주식·출연 가능 재산 | 재무상태표, 주주명부 | 주식 출연형 검토 (세무사 동반) |
| 12 | 회사 자본금 (법인) | 등기부 | 기본재산이 자본금 50% 초과 시 초과액 사용 가능 |

**진단 결과 한 줄 정리 양식**
```
[○○ 사근복 사전 진단]
구성 가능: 예/아니오 · 협의회: 있음/없음 · 기존 복지 규정: ○개 항목
대체 위험: 없음/있음(내용) · 출연 여력: 연 약 ○천만 원 · 중소기업: 예/아니오
판단: 진행 / 조건부(조건) / 보류(사유)
```

## 2. PC 제안서 (장 순서)

AP에서 대표님이 말한 숫자와 고민을 그대로 다시 꺼내는 것으로 시작합니다. 보험 이야기는 넣지 않습니다.

| 장 | 제목 | 내용 | 보여줄 숫자 |
|---|---|---|---|
| 1 | 지난번 말씀 | 대표님 입에서 나온 고민과 목표를 그대로 | 대표님이 말한 숫자 |
| 2 | 지금 구조 | 직원 복지를 급여로 늘릴 때 새는 돈 | 같은 금액을 급여로 줄 때 회사 비용과 직원 실수령 |
| 3 | 기금으로 바꾸면 | 새 복지를 기금으로 할 때 | 출연액, 그해 사용 가능액(50/80%), 직원 1인당 혜택 |
| 4 | 이런 복지를 합니다 | 회사 맞춤 복지사업 3~4개 | 사업별 연간 예산, 대상, 기준 |
| 5 | 이것은 안 됩니다 | 금지선을 먼저 보여 줌 (상여 대체, 기존 복지 감축, 대표 수혜, 출연금 회수) | |
| 6 | 일정과 비용 | 설립 일정표, 용역비, 연간 관리비 | 주차별 일정 |
| 7 | A안 / B안 | 출연 규모 두 가지 (예: 이익의 3% / 5%) | 안별 사용액, 1인당 혜택, 적립액 |
| 8 | 다음 단계 | 노사협의회 의결 일정, 준비 자료 | D-day |

**3장 계산식**
- 출연액 = 직전 연도 세전순이익 × 출연률 (기준 5%, 가감 가능)
- 그해 사용 가능액 = 출연액 × 50% (중소기업·선택적 복지 80%, 협력업체 20% 초과 지원 90%)
- 적립액 = 출연액 − 사용액 → 기본재산 (운용 수익으로 다음 해 사업)
- 자본금 초과 사용 = 기본재산 − 자본금 × 50% (법인만)

**4장 복지사업 고르는 기준**
| 직원 구성 | 추천 사업 |
|---|---|
| 젊은 직원, 무주택 많음 | 주택 임차자금 대부·보조, 결혼·출산 축하금 |
| 자녀 둔 중년층 | 자녀 학자금·학원비, 의료비 (가족 포함) |
| 현장직·교대근무 | 건강검진, 체육·문화 지원, 기숙사(법정 요건) |
| 고르게 섞임 | 선택적 복지 (용도 제한형 포인트) + 경조비 |
| 협력업체와 함께 일함 | 협력업체 근로자 포함 사업 (사용 한도 확대, 공단 지원) |

**PC 클로징 한마디**
> "기금 인가에 20일, 등기까지 한 달 남짓 걸립니다. 올해 결산 전에 출연하시려면 이번 달 안에 노사협의회 의결부터 하셔야 합니다. 협의회 날짜는 언제로 잡을까요?"

## 3. 설립 때 대표님과 정할 것

> 설립·운영 서식은 이 기획의 범위에서 제외합니다. 여기서는 설계 단계에서 대표님과 결정할 사항만 다룹니다.
| 항목 | 선택지 | 권장 |
|---|---|---|
| 수혜 대상 | 근로자만 / 배우자·가족 포함 | 의료비·단체보험 하려면 가족 포함 |
| 차등 기준 | 없음 / 근속연수 | 근속 차등은 합리적 범위에서 가능, 정관에 명시 |
| 대부사업 | 안 함 / 주택·생활안정·학자금 | 하려면 처음부터 근거 규정 |
| 선택적 복지 | 안 함 / 운영 | 운영하면 그해 80% 사용 가능 |
| 협력업체 수혜 | 안 함 / 포함 | 원청이면 포함 검토 (한도 확대·지원금) |
| 운영 경비 한도 | 총 사업비의 ○% | 모의정관은 1/20 |
| 준용 규정 | 넣음 | "정관에 없는 사항은 근로복지기본법령에 따른다" 반드시 |
| 임원 임기 | ○년 | "퇴직 시까지"는 불가 |
| 잔여재산 귀속 | 지정 / 협의회 의결로 지정 | 간접 지정도 유효 |

## 4. 해마다 사후관리 캘린더 (12월 결산 기금 기준)

| 시기 | 할 일 | 근거·기한 |
|---|---|---|
| 1월 | 감사 정기감사 (회계연도 시작 2개월 안) | 정관 |
| 2월 | 결산서·사업보고서 작성, 감사보고서 | |
| 2~3월 | **기금협의회 정기회의**: 결산 승인, 출연액 결정, 사업계획 | 협의회 의결 |
| **3/31까지** | **운영상황·결산서·다음 연도 사업계획서 노동부 보고** | 회계연도 종료 후 3개월 |
| 3월 | 회사 결산 확정 → 출연액 산정 (세전순이익 기준) | |
| 출연 후 3주 안 | **기본재산 총액 변경 보고** | 시행령 제35조 |
| 수시 | 이사 연임·해임 등기 (3주 안), 결원 위원 보충 (30일 안) | |
| 수시 | 복지사업 집행, 대부 심사, 증빙 보관 | |
| 연중 | 회의록·사업보고서 사내 공개 | 미이행 시 200만원 이하 과태료 |
| 11~12월 | 다음 연도 사업 설계 검토, 세무 결산 준비 (세무사) | |

**보관 기간:** 협의회 회의록 10년 / 사업보고서·재무제표·감사보고서 5년

## 5. 자주 막히는 지점과 해법

| 막히는 지점 | 해법 |
|---|---|
| 직원이 적어 감사 겸임 문제 | 협의회 위원과 이사는 겸임 가능, 감사만 따로. 노사 각 3명을 미리 확보 |
| 정관상 정원보다 위원이 줄어듦 | 원칙적으로 무효. 구성이 불가능하면 예외적으로 운영하되 정족수는 지킴 (2019 회시). 결원은 30일 안 보충 |
| 등기 기한(인가 후 3주) 놓침 | 인가 취소 가능. 인가 신청 전에 법무사 일정부터 잡기 |
| 이익이 없는 해 | 협의회 의결로 출연 안 함. 출연 안 한 해는 기본재산 사용(50/80%) 불가, 수익금만 사용 |
| 대표가 상여 대체를 고집 | 회시 근거(2018·2022·2024)를 보여 주고 설계 거절. 무리하게 진행하면 대표 처벌 위험 |
| 기존 복지를 기금으로 옮기고 싶다 | 노사 합의로 단협·규정에 "재원을 기금으로 할 수 있다" 명시 + 정관 근거 (2022 회시). 감축이 아니라 재원 이전임을 회의록에 남김 |
| 기금 운용 상품 선택 | 예금·국공채·A+ 이상 채권은 이사회, 그 외는 협의회. 저축보험은 예입 해당 여부 상품별 확인 |
