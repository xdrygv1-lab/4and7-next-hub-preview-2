# 신세대 트랙: 빠른 시작

> **한눈에** 체크리스트와 예시, 도구 중심으로 빠르게 시작하는 지점원용 안내입니다. 첫 30일 할 일부터 따라 하면 됩니다.

**핵심 4줄**
1. AP 결과물은 계약이 아니라 **다음 약속 + 소개**
2. 제안 전 **선심사**, 고객 화면 숫자는 **실제 가입설계서**
3. 세무 처리는 세무사 검토 사항
4. 수익 약속 표현 금지

## 첫 30일 할 일

| 주차 | 할 일 |
|---|---|
| 1주차 기초 | 표기 규칙 읽기, 용어 사전 A·B 묶음 훑기, 원수사 전산 접속 확인 |
| 1주차 숫자 | 경정기 핵심 숫자: 저해약 **3년 0% / 3~5년 50%**, 감액완납 **5년**, 종신·연금전환 **7년**, 대출 **10년·75세**, 10년 후 매년 **10%** 체증 |
| 2주차 명단 | 기장 거래처 법인 위주 **20~30명** 가망고객 목록(업종·잉여금·핵심이슈·접근명분·관계온도 A/B/C 등), 접근명분 고르기(가결산·결산, 법인전환, 성실신고 후 점검), TA **3건** 이상 |
| 3주차 AP | 전날 **AP 스크립트 생성기**로 초안, 15단계 20분 구조 숙지(진입 5분·전개 7분·전환 3분·정보수집 3분 30초·클로징 1분 30초), 끝에 **일자+시각+소요시간** 약속 확정, 녹음 피드백 |
| 4주차 제안·청약 | 선심사 → 재정심사 범위 확인, **경정기 시뮬레이터**로 후보 비교 → 실제 설계서, PC 자료(AP 복기 → 전/후 → A/B안 → D-day), 첫 청약은 선배와 동행 |

## 예시로 이해하기

**1억 보장, 10년 뒤 순비용**

| 상품 | 월보험료 | 10년 총납입 | 10년 환급금 | 순비용 |
|---|---|---|---|---|
| 타사 경정기 A | 412,000원 | 4,944만 | 4,736만 | **208만** |
| TheClassic 달러 | 515,200원 | 6,182만 | 5,867만 | **315만** |
| TheClassic 원화 | 367,000원 | 4,404만 | 3,990만 | **414만** |

- 달러형은 가입금액 **$10만**(약 1.4억, 환율 1,400원 가정)이라 보장금액이 다릅니다.
- 원화형은 환급률은 낮지만 보험료가 가장 낮아 "같은 예산으로 보장 최대화"에 맞습니다.

**일반 vs 간편 (40세, 1억):** 달러 515,200원 → 623,000원(**+21%**), 원화 367,000원 → 440,000원(**+20%**). 같은 예산이면 보장 약 **17%** 감소, 2년 내 질병 사망 시 50%.

**70세 이상 대표:** 경정기 10년 환급률이 **60%대**로 떨어져, 종신·상속형 검토가 맞습니다.

## 금지어 vs 대체 표현

| 쓰지 않는 말 | 대신 이렇게 |
|---|---|
| 세무 효과를 단정하는 말 | 처리 방식은 세무사와 결정합니다 |
| 전환하면 세금 없이 넘어가요 | 세무 처리는 세무사 검토 사항입니다 |
| 확정 수익 / 무조건 남아요 / 저축이에요 | 보장성 보험입니다. 중도 해지 시 원금 손실이 있을 수 있습니다 |
| 10년 뒤 95% 돌려받아요(먼저 꺼내기) | 완납·유지 전제, 환급률은 설계서 기준 |
| 달러라서 안전해요 | 환율이 내리면 원화 기준 손실이 날 수 있습니다 |
| 상속세 최고 40% | 현행 최고세율 **50%**(최신 세법 확인) |

## 도구 활용

| 도구 | 한 줄 사용법 |
|---|---|
| AP 스크립트 생성기 | 상황카드 입력 → 컨셉 진단 + 15단계 초안. 실제 파악한 정보만 |
| 경정기 시뮬레이터 | 나이·성별·심사·금액 → 상품별 환급률·순비용 비교 |
| 용어 사전 | 검색으로 찾기 |

- ⚠ 도구 수치는 **내부 검토용**, 고객 자료는 실제 가입설계서
- 시뮬레이터의 40·50·60·70세 외 나이는 **추정값**
- 고객 실명·주민번호는 넣지 않기, "OO산업 김 대표님" 수준으로 익명화
