# 노무사의 첫 미팅 (사근복 중심)

> **한눈에** 사업단 AP 15단계를 노무사 상황에 맞게 바꾼 흐름입니다. 노무사의 접점은 결산이 아니라 **급여·4대보험·연차·근로계약 시즌**입니다. AP의 산출물은 계약이 아니라 **다음 약속과 소개**이고, 보험 이야기는 하지 않습니다.

## 노무사가 들어가는 명분

| 관계 | 03단계 명분 예시 |
|---|---|
| 노무 자문·급여 아웃소싱 거래처 | "작년에 거래처 한 곳이 퇴사자 진정 하나로 3년치 수당을 소급해서 물어주는 걸 봤습니다. 그 뒤로는 문제가 터지기 전에 미리 봐 드리는 쪽으로 일하는 방식을 바꿨습니다." |
| 소개받은 자리 | "○○ 대표님이 직원 복지 고민하시는 분이라고 꼭 만나 보라고 하셨습니다." |
| 처음 만남 | "자문 계약 받으러 온 게 아닙니다. 오늘은 인건비와 복지 이야기를 들으러 왔습니다." |

## 시즌별 진입 타이밍
- **1~2월:** 연봉협상, 연차 정산, 최저임금 변경 → "올해 복지는 어떻게 하실 거예요?"
- **3월:** 결산 확정 → 출연 가능액 계산 (직전 연도 세전순이익 기준)
- **6~7월:** 상반기 실적 → 성과급 고민 (⚠ 성과급은 기금으로 불가, 대신 새 복지 설계)
- **11~12월:** 다음 연도 사업계획 → 기금 사업계획서 작성 시기

## 15단계 노무사 버전 (핵심만)

| 단계 | 노무사 버전 멘트 | 주의 |
|---|---|---|
| 02 동질감 | "저도 노동법이 매년 바뀌어서 계속 공부하는데, 해마다 조금씩 나아지는 것 같습니다." | |
| 04 방문목적 | "급여 정리도 정리지만, 대표님이 직원들 어떻게 챙기고 싶으신지 들어보려고요." | 목적을 처음에 두 개로 |
| 05 시간확보 | "급여 이야기 20분, 대표님 이야기 20분 괜찮으실까요?" | |
| 06 일반 팩트 | "회사가 직원에게 급여로 100을 더 주면, 회사는 100보다 더 쓰고 직원은 100보다 덜 받습니다." | 4대보험 요율은 그해 기준으로 |
| 07 우리 회사 숫자 | "직원 ○명이면 4대보험 회사 부담분만 연 ○천만 원입니다." | 상대 회사 숫자로 |
| 08 니즈환기 | "직원들이 제일 원하는 게 뭘까요?", "핵심 직원 붙잡을 카드가 급여 말고 있으세요?" | 질문만 |
| 09 문제제기 | "복지를 늘리고 싶은데 급여로는 새고, 한 번 올리면 못 내립니다." | 숫자 두 개 나란히 |
| 10 선거절처리 | "이익이 안 나는 회사는 이런 고민 자체를 안 합니다." | 저항 먼저 |
| 11 대안제시 | "회사가 쓴 만큼 직원에게 그대로 가는 구조가 있습니다." | 제도 이름·세부는 다음에 |
| 14 F.F | 직원 수(고용형태별), 노사협의회, 취업규칙상 복지, 재무제표 | 대안 뒤에 질문 |
| 15 다음 약속 | "대표님 회사 숫자로 출연 가능액과 직원 혜택을 계산해서 목요일 오후 2시에 가져오겠습니다. 한 시간 잡아 주세요." | 일자+시각+소요시간 |
| ☆ 소개요청 | "직원 복지 고민하시는 대표님 딱 두 분만 소개해 주세요." | 대상·인원 특정 |

## 노무사만 할 수 있는 확인 질문
- "근로계약서와 임금명세서는 매번 교부하고 계세요?"
- "취업규칙은 마지막으로 언제 고치셨어요?"
- "상여나 복지포인트를 정기적으로 주고 계세요?" (통상임금·기존 복지 확인)
- "노사협의회는 구성돼 있나요?" (30인 이상 의무, 사근복 설립 합의 기관)

## 꼭 지킬 것
- [ ] 상품명·보험 이야기를 하지 않았다
- [ ] "상여를 기금으로 바꾸면 된다"는 말을 하지 않았다
- [ ] 대표 본인이 혜택을 받을 수 있다는 기대를 주지 않았다
- [ ] 다음 약속을 일자·시각·소요시간까지 확정했다
- [ ] 소개요청에서 대상과 인원을 특정했다
