# 변액유니버셜 모두의상속종신

## 상품 요약

> **한눈에** 사망 시 기본보험금액, 계약자적립액의 **105%**, 기납입보험료 중 가장 큰 금액을 주는 변액유니버셜 종신보험입니다. 펀드 실적이 나빠도 계약유지보증기간 동안 기본보험금액(최저사망보험금)은 보증하지만 **해약환급금 최저보증은 없습니다**. 상속재원을 준비하는 법인 대표·자산가 상담과 변액 경영인정기(MAVERICK) 이해의 기초로 씁니다.
> 내부 참고용. 고객에게는 가입설계서·상품설명서 기준으로 안내.

### 핵심 조건 표
| 항목 | 일반가입형 | 간편가입형 |
|---|---|---|
| 가입나이 | 만 **15세**~ (5·7·10년납 ~70세, 20년납 ~60세 등 납입기간별) | **30세**~ (5년납 ~75세, 7년납 ~73세 등) |
| 가입금액 | **2천만원~50억원** | **2천만원~20억원** |
| 보험기간 / 납입 | 종신 / 월납. 5~30년납, 55·60·65·70·80세납 | 동일 |
| 최소의무납입 | **36개월** | 동일 |
| 사망보험금 | 기본보험금액·적립액 105%·기납입보험료 중 최대 | 동일. 단 **2년 미만 재해 외 사망 시 50%** |
| 최저사망보험금 보증 | 종신·80세·65세 보증 (60세 초과 가입 시 최단 80세) | 동일 |
| 해약환급금 | 최저보증 **없음** (원금손실 가능) | 동일 |

### 해약환급금 예시 (일반, 1억원, 20년납, 40세 남, 채권 70% + 주식 30%, 만원)
| 경과 | 납입 | 투자수익률 -1.00% | 2.50% | 3.75% |
|---|---|---|---|---|
| 1년 | 212 | 0 (0.0%) | 0 (0.0%) | 0 (0.0%) |
| 5년 | 1,064 | 377 (35.4%) | 419 (39.4%) | 435 (40.9%) |
| 10년 | 2,128 | 843 (39.6%) | 1,009 (47.4%) | 1,077 (50.6%) |
| 20년 | 4,257 | 1,925 (45.2%) | 2,681 (63.0%) | 3,037 (71.3%) |
| 40년 | 4,257 | **0 (0.0%)** | 2,312 (54.3%) | 4,297 (100.9%) |

-1% 가정 시 40년 시점 0: 실적이 부진하면 장기 유지 중 적립액이 소진될 수 있습니다. 미래 수익 보장 아님.

### 유니버셜 기능
- **추가납입**: 기본보험료 완납 후 수시, 최소 **10만원**. 총한도 기본보험료 총액의 **200%**. 추가납입분은 기본보험금액에 그대로 더해짐
- **중도인출**: 36개월 후, 해약환급금의 **50%** 이내, 연 **4회**. 인출액만큼 기본보험금액 감소
- **납입유예**: 해약환급금에서 월대체공제 가능 시. 과도하면 조기 해지·보증기간 단축

### 이런 고객에게
- 사망 시점과 관계없이 기본보험금액 이상을 남기고 싶은 상속재원 설계 고객
- 여유자금을 추가납입해 상속재원으로 옮기고 싶은 자산가
- 실적이 좋으면 사망보험금이 늘어나는 구조를 원하는 고객

### 설명할 때 꼭 말할 것
- ⚠ 해약환급금 최저보증이 없어 **원금손실 가능**, 손실은 계약자 몫
- ⚠ 보증 테스트를 '충분'으로 유지해야 최저사망보험금이 보증됩니다. **기준보험료 이상 꾸준히 납입, 인출 최소화**
- ⚠ 계약자·납입자가 **법인이면 예금자보호 대상이 아닙니다**
- ⚠ 해약환급금으로 월대체공제를 못 하면 해지될 수 있습니다
- ⚠ 초기 환급률이 매우 낮음 (1년 **0%**, 2년 **4.2~6.4%**)

> "대표님, 펀드 실적이 나빠도 사망보험금은 기본금액이 보증되지만, 해지환급금은 보증이 없습니다. 그래서 꾸준히 납입하시는 것을 전제로 설계합니다."

### 자주 헷갈리는 점
| 헷갈리는 점 | 정리 |
|---|---|
| 해약환급금도 보증? | **사망보험금만** 최저보증. 해약환급금은 보증 없음 |
| 36개월 이후엔 마음대로 쉬어도? | 월대체공제가 계속 빠져 적립액이 줄고 해지될 수 있음. 보증 유지 여부는 테스트 결과에 따름 |
| 비용은 얼마? | 운용보수·보증비용·사업비 요율이 요약서에 없음. 사업방법서·상품설명서로 확인 |
| 갱신형 특약도 납입 끝나면 끝? | 주계약 납입 완료 후에도 특약 만기까지 보험료 납입, 갱신 시 인상 가능 |

### 꼭 확인할 것
- [ ] 70·80세납 일반가입형 최저나이는 설계 시스템에서 재확인
- [ ] 운용보수·보증비용·사업비 요율, 펀드 변경 조건 확인
- [ ] 펀드장기유지보너스 지급률
- [ ] 법인 계약 시 예금자보호 미적용 고지
- [ ] 상속세 재원·계약자/수익자 설계의 세무 처리는 세무사 검토 사항

## 자주 묻는 질문

> **한눈에** 보험료 일부를 펀드로 운용하는 **변액유니버셜 종신보험**입니다. 조건을 지키면 사망보험금 최저 금액은 보증되지만 **해약환급금은 보증되지 않고 원금손실이 가능**합니다. 원금손실을 이해하고 장기 납입이 가능한 상속재원 고객에게 맞습니다.

⚠ 수익률은 매일 변동하고 손실은 계약자 귀속입니다. 법인이 계약자·보험료납부자면 **예금자보호 대상이 아닙니다.**

### 이런 고객에게
- 언제 사망하든 기본보험금액 이상이 나오는 상속재원을 원하는 고객
- 여유자금을 추가납입으로 상속재원에 더하고 싶은 고객(추가납입분은 기본보험금액에 더해짐)
- ⚠ 맞지 않음: 원금손실을 받아들이기 어려운 고객, 36개월 의무납입이 어려운 고객, 법인 계약으로 예금자보호를 기대하는 고객

### 자주 묻는 질문

**Q. 펀드가 나빠지면 사망보험금도 줄어드나요?**
A. 보증 테스트가 "충분"이면 기본보험금액은 보증됩니다. 납입 부족·중도인출·미상환 대출이 불리합니다.

**Q. 해약환급금도 보증되나요?**
A. 아닙니다. 원금손실 가능, 손실은 계약자 귀속입니다.

**Q. 법인 계약자로 해도 되나요?**
A. 제한 언급은 없지만 법인이 계약자·납부자면 **예금자보호 대상 아님**. 반드시 고지합니다.

**Q. 예금자보호는 어디까지인가요?**
A. 최저사망보험금과 특약에 한해 1인당 **1억원**(타 보호상품 합산). 적립금 전체가 아닙니다.

**Q. 펀드 비율은 어떻게 권하나요?**
A. 장기채권형 **30% 이상** 필수. 특정 비율을 권하지 않고 고객 성향에 맞춰 고객이 선택합니다.

**Q. 3년 안에 해지하면?**
A. 1년 0%, 3년 21.8~25.2%로 손실이 큽니다.

**Q. "최저보증 3%"라던데요?**
A. 3.00%는 최저사망보험금 보장부분 이율이지 적립액 보증이 아닙니다.

**Q. 비용(사업비)은?**
A. 요율이 요약서에 없어 상품설명서로 확인합니다.

**Q. 자녀를 계약자로 하는 구조도 되나요?**
A. 자녀의 **실질** 보험료 부담이 전제입니다. 세무 처리는 세무사 검토 사항입니다.

**Q. 변액 판매 자격은?**
A. 자료에 없어 원수사·GA 준법 기준으로 확인합니다(확인 필요).
