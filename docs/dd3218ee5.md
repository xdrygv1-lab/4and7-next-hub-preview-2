# 사근복 되는 것과 안 되는 것

> **한눈에** 기금으로 할 수 있는 사업과 할 수 없는 사업을 노동부 회시 기준으로 정리했습니다. 기준은 하나입니다. **회사가 원래 줘야 하는 것이 아니고, 일한 대가도 아니며, 용도나 요건이 정해진 복지**여야 합니다.

## 임금 대체 판단 기준 (퇴직연금복지과-341, 2021)
1. 근로 제공의 대가인가
2. 여행·건강·문화·체육 등 **실제 사용 용도에 따라** 지급되는가
3. 주택자금·장학금·재난구호금·경조사비처럼 **정해진 요건에 따라** 지급되는가

→ 성과 보상 성격으로 용도와 관계없이 전 직원에게 일률적으로 현금을 주면 **임금 대체**입니다.

## 목적사업

| ✅ 가능 (정관에 근거 필요) | ❌ 불가 |
|---|---|
| 무주택자 주택 구입·임차 보조·대부 | 전 직원에게 일률적으로 주택자금·휴가비·월동비·체력단련비·유류비 명목 현금 |
| 근로자·자녀 장학금, 학원비, 유치원비 | 회사가 줄 의무가 있는 퇴직금, 명예퇴직 위로금, 퇴직자 전별금 |
| 재난구호금, 경조비, 의료비·건강진단비 (가족 포함 가능) | **성과급·격려금·포상금·우수사원 포상** |
| 용도가 정해진 선택적 복지포인트 | 4대보험 사용자 부담분, 업무 출장비·연수비, 업무용 비품·근무복 |
| 체육·문화 관람료, 동호회비, 근로자의 날 행사 | 특정 직급·부서·노조원만을 위한 지원 |
| 명절·창립기념 선물, 상품권, 생일·출산 축하금 | 일반 아파트·빌라를 사서 기숙사로 쓰기, 호텔, 요트 |
| **전 직원** 단체보험·개인보험 가입 지원 | **특정 직원·부서만** 보장성(종신)보험 |
| 개인연금·IRP 근로자 부담금, 대출이자 지원 | 사업주 의무 직장어린이집 운영 |
| 우리사주조합을 통한 구입 지원·대부 | 조합 없이 자사주 매입 지원 |
| 법정 요건 기숙사, 구내식당, 사내카페, 콘도, 전 직원용 골프회원권 | 근로자가 아닌 사람(불우이웃, 친목회)에게 기부 |

## 수혜 대상

| ✅ 가능 | ❌ 불가 |
|---|---|
| 재직 근로자 (정규·계약·단시간·아르바이트·해외 현지채용) | **대표이사, 업무집행권 있는 임원** |
| 근로자성이 인정되는 임원 (개별 판단) | 임원 전원을 일괄로 넣기 |
| 배우자·가족, 사망 근로자 유족 (정관 규정 시) | 퇴직자 |
| 직접 도급업체 근로자, 파견근로자 | 자회사·가맹점 근로자 (도급·파견 관계가 아니면) |
| 대표 자녀라도 실제 근로자면 배제 불가 | |

## 기존 복지를 기금으로 옮길 때
- 단체협약·취업규칙·내부규정에 있는 복지는 **원칙적으로 불가**
- 노사 합의로 규정을 고쳐 "재원을 기금으로 할 수 있다"고 명시하고, 정관에도 근거를 두면 가능
- ⚠ 기금 설치를 이유로 기존 복지를 **중단·감축**하면 사용자 **1년 이하 징역 또는 1천만원 이하 벌금**

## 돈을 굴리는 방법 (운용)
- 가능: 금융회사 예입·금전신탁(MMT 포함), 수익증권(ELS·ELB 등), 국가·지자체·금융회사 발행·보증 유가증권, 투자회사·리츠 주식, 출연받은 자사주로 유상증자(기본재산 20% 이내)
- 저축보험: "금융회사 예입"에 해당하면 가능 (상품별 확인)
- 불가: 일반 기업 회사채, 신종자본증권, 업무용이 아닌 부동산
- 기금의 20% 이상 또는 10억 이상을 투자하면 외부 투자자문 필요

> 근거: 실무 매뉴얼(2025) 44~71쪽, '25 질의회시집 7·8장
