# 보험용어 사전

> **한눈에** 지점원이 꼭 알아야 할 보험용어를 7개 묶음으로 나눠 한 줄 뜻과 예시로 정리했습니다. 모르는 단어가 나오면 검색해서 바로 찾아 쓰세요.

⚠ 예시 숫자는 2026년 9~10월 자료 기준입니다. 고객에게 보여줄 숫자는 반드시 **실제 가입설계서**로 확인합니다.

## A. 계약 구조

| 용어 | 쉬운 뜻 | 예 |
|---|---|---|
| 계약자 | 계약하고 보험료 내는 사람(법인). 해지·변경 권한 보유 | 법인 경정기: 계약자 = 법인 |
| 피보험자 | 생명·건강이 보험 대상인 사람 | 법인 경정기: 피보험자 = 대표 |
| 수익자 | 보험금을 받는 사람 | 법인 경정기: 수익자 = 법인. 유족 지정 시 처리 달라짐(세무사 검토) |
| 타인의 사망보험·서면동의 | 계약자≠피보험자면 피보험자 서면동의 필수, 없으면 무효 | 대표 자필 서명 필수 |
| 서면동의 철회 | 피보험자가 동의를 철회하면 계약 해지 | 대표 교체·지분 분쟁 가능 법인은 미리 안내 |
| 주계약 / 특약 | 상품 본체 / 덧붙이는 옵션(자동부가 포함) | 종신전환·연금전환특약 자동부가 |
| 보험가입금액 | 보장의 기준 금액 | 달러 경정기 일반 **5만~500만달러** |
| 보험기간 / 납입기간 | 보장 기간 / 내는 기간. 같으면 "전기납" | **90세** 만기, 90세납 |
| 보장개시일 | 보장 시작일. 첫 보험료 내면 승낙 전 사고도 원칙적 보장 | 첫 출금일 미리 확인 |
| 계약자 변경 | 계약자를 바꾸는 것, 회사 승낙 사항 | 법인 → 대표는 확정 제안 금지(세무사 검토) |
| 지정대리청구 | 수익자가 청구 못 할 때 지정 대리인이 청구 | 사망보험금 제외 |
| 보험증권 | 계약 성립 증서, 청약철회 기간 기준 | 전달 때 보장분석 함께 |

## B. 보험료·환급

| 용어 | 쉬운 뜻 | 예 |
|---|---|---|
| 해약환급금 | 중도 해지 때 돌려받는 돈, 낸 돈보다 적을 수 있음 | 40세 남 일반 1년차 **0달러** |
| 환급률 | 해약환급금 ÷ 낸 보험료. 100% 미만이면 원금 손실 | 40세 일반 10년 **94.9%** |
| 순비용 | 낸 보험료 − 해약환급금 = 보장 비용 | 1억 보장 10년 상품별 **208만~414만** |
| 유해약환급금형 | 환급금을 정상 지급하는 기준형, 주로 비교용 | "비교 안내용" |
| 저해약환급금형 | 일정 기간 환급금을 줄이고 보험료가 쌈 | 3년 전 **0%**, 3~5년 **50%**, 5년~납입 끝 **95%**, 납입 후 **100%** |
| 무해약환급금형 | 납입 중 환급금 0%, 보험료 가장 쌈 | 납입 중 **0%**, 납입 후 **50%** |
| 체증형 | 시간이 지나면 사망보험금 증가 | 10년 후 매년 **10%** / 매년 **5%** 150%까지 / 매년 **20%** 30년 후 700% |
| 단기납 | 5·7·10년 짧게 내는 종신 | 5년납 40세 남 10년 **124.9%** |
| 유지보너스 | 납입 후 유지하면 더해 주는 보너스, 해지 시 없음 | 10년 **7.5%**, 20년 **3.8%** / **39.7%** |
| 적용이율 | 계산·적립용 이율. "수익률" 아님 | 달러 10년 내 **3.75%**, 이후 1.0% / 원화 **2.5%**, 이후 1.0% |
| 계약자적립액 | 계약별 적립금, 환급금 계산 기초 | 대출 원금·이자 빼고 계산 |
| 감액 | 가입금액 줄이기, 줄인 부분은 해지로 봄 | 감액분 환급금이 적을 수 있음 |
| 감액완납 | 납입 멈추고 환급금으로 금액 줄여 유지 | 계약 **5년** 경과 후, 회사 승낙 |
| 보험계약대출 | 환급금 범위 내 대출, 이자 붙고 보험금에서 차감 | 전기납 + 10년 미경과 + **75세** 이하 |
| 추가납입 | 기본보험료 외 추가 납입, 상품마다 다름 | 일반 추가납입 규정 없음(원화고정납입용만) |
| 중도인출 | 해지 없이 적립액 일부 인출 | 자동인출 외 불가 |
| 원화고정납입 | 달러 상품을 매달 같은 원화로 납입 | 추가보험료 한도 **50%** |
| 원화환산납입·지급 | 달러 상품을 원화로 내고 받는 특약 | 환율 리스크는 남음 |
| 플러스보험기간 | 달러 경정기 90세 만기 후 **5년** 연장 보장 | 대출 잔액만큼 줄어듦 |
| 종신전환 | 경정기를 종신으로 전환(기존 해지 후 일시납) | **7년** 이상 정상 유지 후 |
| 연금전환 | 계약을 연금으로 전환 | 7년 경과 + 환급금 **1,000만원(1만달러)** 이상 |
| 조기 계약전환 | 사유 발생 시 7년 전에도 종신 전환 | 36회 이상 납입 + 폐업·3개월 입원·대표 변경·최대주주 변경 |
| 납입최고·실효 | 연체 시 **14일** 이상 독촉 후 해지 | 최고 기간 다음 날 해지 |
| 부활 | 연체 해지 계약을 되살림, 재심사 | 해지일부터 **3년** 이내 |
| 선납 | 보험료 미리 내기 | **12개월**, 일부 회사 6개월 |
| 납입유예 | 출산·육아휴직 때 납입 잠시 미룸 | 계약당 1회, 6개월 또는 12개월 |
| 보험가격지수 | 업계 평균 대비 가격, 높을수록 비쌈 | 일반 **100.2%**, 간편 **121.2%** |

## D. 상품

| 용어 | 쉬운 뜻 | 예 |
|---|---|---|
| 보장성 보험 | 위험 보장 목적, 저축 상품 아님 | "저축·재테크 목적 아님" |
| 정기보험 | 정해진 기간만 보장, 만기 환급 없음 | 90세 만기 환급금 0 |
| 종신보험 | 평생 사망 보장 | 상속세 재원·가족 보장 |
| 단기납 종신 | 짧게 내고 이후 환급률 상승 | 7년납 + 3년 유지(7+3) |
| 원금형 종신 | 일정 기간 뒤 환급률이 원금 수준 | 7년차 **100%** 예시 |
| 체증형 종신 | 사망보험금이 해마다 증가 | 자산이 늘어나는 오너의 상속재원 |
| 보장형(무해약) 종신 | 환급금 줄이고 사망보험금 레버리지 ↑ | 사망보험금이 확실히 필요할 때 |
| 달러보험 | 기준 통화가 달러, **환율 하락 시 원화 손실 가능** | 장점만 말하면 불완전판매 |
| 변액보험 | 펀드 운용, 원금 손실 가능 | 공시 수익률 ≠ 개인 수익률 |
| 변액유니버셜 | 변액 + 납입·인출 유연성 | 최소의무납입 **36개월** |
| 최저사망보험금 보증 | 기본 사망보험금 보증, 환급금은 보증 안 함 | 환급금 최저보증 없음 |
| 변액 경정기(MAVERICK) | **2026.10.20** 출시 예정, 세부 미공개 | 출시 전엔 기존 경정기 기준 상담(확인 필요) |
| 연금보험 | 일정 나이부터 연금 수령 | 경정기·종신에서 전환 가능 |
| 무배당 | 계약자 배당 없음 | 대부분 현재 상품 |
| 예금자보호 | 보험사 파산 시 일정액 보호, 변액 특별계정은 제외될 수 있음 | 1인당 **1억원** |

## E. 세무

세무 처리(비용처리·손금·익금 등)는 세무사 검토 사항입니다. 아래는 개념만 알아 두세요.

| 용어 | 쉬운 뜻 | 예 |
|---|---|---|
| 법인세상 비용·수익·자산 처리 | 보험료와 환급금을 장부에 어떻게 올릴지 | 세무 처리는 세무사 검토 사항 |
| 원금형 종신 법인 처리 | 세무사 검토 사항 | 단정 금지 |
| 종신전환 시 처리 | 세무사 검토 사항 | ⚠ "전환하면 세금 없이 넘어간다" 금지 |
| 퇴직 시점 매칭 | 세무사 검토 사항 | 정관·임원퇴직급여지급규정 정비가 먼저 |
| 규정 개정 | 세무사 검토 사항 | 개정 시점·소급 리스크 확인 |
| 임원 퇴직소득 한도 | 퇴직소득 인정 한도, 2020년 이후분 **2배수**, 초과분 근로소득 | 대표 개인 세부담 별도 계산 |
| 가입 중 대표 근로소득 | 계약자·수익자가 법인이면 대표 근로소득 아님 | 유족 수익자면 달라짐 |
| 계약 이전 평가 | 법인 → 대표 이전 시 평가 기준 미확정 | **확정 제안 금지**, 사전답변 검토 |
| 부당행위계산 | 특수관계인에게 싸게 넘기면 부인(차액 **3억원** 또는 시가 **5%** 이상) | 초기 환급금으로 낮게 넘기는 설계 위험 |
| 달러보험 환산 | 법인 달러보험 환차 처리 해석 없음 | 추가 확인 필요 |
| 사전답변 | 거래 전 국세청 해석 받기, 수개월 소요 | 고액·새 구조일 때 |
| 상속세 최고세율 | 현행 **50%**, 40% 표기는 정정 대상 | 최신 세법 확인 |
