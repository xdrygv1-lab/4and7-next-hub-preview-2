# 청약서 작성 가이드

> **한눈에** 청약 전 체크리스트, 작성 순서, 자주 하는 실수, 심사 대비, 청약 후 관리를 정리했습니다. 첫 청약을 앞둔 지점원이 출력해서 들고 가는 용도입니다.

⚠ 회사별 전산 화면·서류 양식·전자청약 절차는 자료에 없습니다. 최종 기준은 원수사 확인이 필요합니다(확인 필요).

## 1. 청약 전 체크리스트

**상품·심사**
- [ ] **선심사를 먼저** 넣었다(설명 다 했는데 가입 안 되는 상황 방지)
- [ ] 일반/간편 선택 이유를 설명했다. 간편은 보험료 약 **20%** 높고, 같은 예산이면 보장 약 **17%** 줄어든다
- [ ] 일반 가능자를 간편으로 넣으면 **보험료 비교 설명 + 계약자 확인서** 준비
- [ ] 청약 직전 **3개월** 내 일반심사 가입 이력 확인(있으면 일반가입형 재심사)
- [ ] 간편가입 **2년 내 질병 사망 시 50%** 지급을 고지했다
- [ ] 가입나이·상품 정식명칭을 설계 시스템에서 재확인했다(예: 달러 경정기 일반 남 **20~70세** / 간편 **30~75세**)
- [ ] 법인 **설립 2년 미만** 여부 확인(회사별 인수 제한, 확인 필요)
- [ ] 조인(분할) 계약이면 원수사에 **합산 인수 가능 여부** 먼저 확인

**고지의무**
- [ ] 고지는 **청약서에 서면으로**. 말로 한 것은 효력 없음
- [ ] 대표와 질문을 하나씩 읽었다: **5년 이내 암 진단, 2년 이내 수술·입원**
- [ ] 간편심사도 "병력이 해소되셨습니까"까지 확인
- [ ] ⚠ 고지를 줄이거나 빼라고 권하지 않았다. 책임은 설계사에게 돌아온다

**재정심사**
- [ ] 소득서류가 필요한 구간인지 확인(기계약 합산, 회사 기준)
- [ ] 고지소득이 **월납 보험료·직업과 앞뒤가 맞는지** 확인
- [ ] 요구받지 않은 서류를 **셀프 제출하지 않았다**(제출 서류는 모두 검토 대상)
- [ ] 경정기 재정심사 기준은 자료가 없어 원수사 언더라이팅팀에 직접 확인(확인 필요)

**설명 자료**
- [ ] **실제 가입설계서** 출력, 1쪽 "저축·재테크 목적의 상품이 아닙니다" 문구를 함께 읽음
- [ ] 저해약 구간(**3년 전 0%, 3~5년 50%**) 설명
- [ ] 달러 상품이면 **환율 하락 시 원화 손실 가능·환전 비용** 설명
- [ ] 세무 처리는 세무사 검토 사항으로 안내
- [ ] 보험사 내부 교육용 자료를 캡처해 보여 주지 않았다

## 3. 자금 원천·고액 거래

| 기준 | 내용 | 상태 |
|---|---|---|
| 고액현금거래 | 1거래일 **1천만원** 이상 현금 거래 자동보고 | 확인 필요 |
| 외화 환전 | 1일 **1만불** 초과 통보, **2만불** 초과 취득경위 입증 | 규정 수시 변경, 확인 필요 |

| ⚠ "현금 원천을 만든다" 표현 | 자금 원천 조사·증여 쟁점 소지 | 사용 금지 권장 |

## 4. 작성 순서
1. 실제 가입설계서로 상품·가입금액·납입기간·심사유형 확정
2. 원수사 매니저에게 **작성예시**를 받아 형광펜 표시 후 연습, 한 번 더 검증
3. 매니저 사전 질문: 불완전판매 주의점, 제출 방법, 출금일, 병력, 원화고정납 금액, 계약자·피보험자 기재
4. 청약 당일 **지점원 직접 동행**
5. 기재: 계약자 = 법인(인감), 피보험자 = 대표(서명), 수익자 = 법인
6. 고지의무: 피보험자가 직접 읽고 답하고 서명
7. 피보험자 **서면동의(자필 서명)**, 없으면 계약 무효
8. 상품설명서·확인서 서명, 고객보관용 서류 전달
9. 부속서류·주주명부 날인, 인감증명서 원본·사본 서류 수령
10. 첫 보험료 법인통장 출금 확인
11. 원본 서류 발송 또는 전산 제출(방법 확인 필요)
12. 해피콜·완전판매모니터링 안내

## 5. 자주 하는 실수

| 실수 | 예방 |
|---|---|
| 건강 이력을 말로만 듣고 안 적음 | 청약서에 서면 고지 |
| 고지소득을 보험료보다 낮게 적음 | 월납 대비 소득 확인 |
| 직업과 안 맞는 고소득 고지 | 직업·소득 일치 확인 |
| 요구 안 한 재무서류 셀프 제출 | 요구받은 서류만 |
| 간편 가입 시 비교 설명 누락 | 비교 설명 + 확인서 |
| 피보험자 서면동의 누락(무효) | 대표 자필 서명 확인 |
| 환급률·"원금 회복"으로 먼저 설득 | 보장 목적 먼저, 완납 전제 |
| 달러 장점만 설명 | 환율 손실 가능성 고지 |
| "절판" 이유로 서둘러 청약 | 고객이 이해·준비된 뒤 청약 |
| 조인 합산 인수 미확인 | 원수사 사전 확인 |
| 근거 없는 실무 메모 그대로 따름 | 원수사 지침으로 확인 |
| 계약자·피보험자 칸 바꿔 기재 | 작성예시와 대조 |
| 사용인감 날인 | 인감증명서와 대조 |

## 6. 심사 대비

⚠ 아래는 한 보험사 **종신 계열** 재정심사 예시이며 경정기 기준이 아닙니다. 현재 적용 여부는 확인 필요입니다.

**고지소득 인수 구간 예시**

| 대상 | 기계약 합산 | 심사 | 소득서류 |
|---|---|---|---|
| 비체증형·체증형 종신 | **5억** 이하 | 고지소득 | 불필요 |
| 체증형 종신 | **5억 초과~7억** 이하 | 재정질의서 | 불필요 |
| 법인 설립 2년 미만 | 가입금액 **5억** 이하 & 월납 **300만** 이하 | | 불필요 |

**사망보험금 인정범위 예시(연간소득 배수)**

| 나이 | 일반고객 | 상위 등급 |
|---|---|---|
| 39세 이하 | 30배 | 35배 |
| 40~49세 | 25배 | 30배 |
| 50~59세 | 15배 | 20배 |
| 60세 이상 | 10배 | 15배 |

- 예: 45세, 연소득 1억원 → 상위 등급 기준 **30억원**까지. 실제 인수는 기계약·건강심사에 따라 다름
- ⚠ 하지 말 것: 보험료 대비 부족한 소득 고지 / 셀프 서류 제출 / 신빙성 없는 소득 고지 / 동업사 합산 **50억** 초과 시 소득서류 필요
- 상품 한도(달러 경정기 일반 **500만달러**·간편 **200만달러**, 원화 일반 **50억원**·간편 **30억원**, 65세 초과 **20억원**)는 **재정심사 한도가 아닙니다.** 배수·업력 기준은 원수사 확인(확인 필요)
- 재정심사 범위 내 가입이 세무 쪽 방어선이기도 합니다.

## 7. 청약 후 관리

| 항목 | 내용 |
|---|---|
| 청약철회 | 증권 받은 날부터 **15일** 이내, 청약일부터 **30일** 넘으면 불가. 상품별로 "30일" 표기도 있음(확인 필요) |
| 철회 불가 | 건강진단 지원 계약, 전문금융소비자(상장법인 등), 30일 초과 |
| 해피콜·완판모니터링 | 대표에게 미리 안내(회사별 시기·방식 확인 필요) |
| 품질보증해지 | 서류 미전달·설명 누락·자필 누락 시 취소 가능(기간 확인 필요) |
| 첫 납입까지 케어 | 대표가 불안해하는 기간에 연락 |
| 증권 전달 | 한 달 뒤쯤 방문 전달, 보장분석 |
| 연체 | **14일** 이상 납입최고 후 해지, **3년** 내 부활 가능(재심사) |
| 변경 시점 | 감액완납 5년 / 계약대출 10년 이내·75세 이하 / 종신·연금전환 7년 / 조기전환 36회 + 사유 |
| 사후관리 | 3개월 차, 결산 1개월 전 브리핑, 2년 후 재방문 |

## 꼭 확인할 것
- [ ] 회사별 전산 화면 순서, 전자청약 가능 여부, 원본 발송처
- [ ] 회사별 법인 필수 서류와 발급일 기준
- [ ] 경정기 재정심사 기준(매출·순이익·자본 배수, 업력, 합산)
- [ ] 해피콜·완판모니터링 시기, 품질보증해지 기간
- [ ] 고객거래확인서 기준, 외화 환전 최신 규정
- [ ] 청약철회 기간 상품별 차이
