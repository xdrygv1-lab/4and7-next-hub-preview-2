## 공개 규칙 때문에 뺀 것

| 무엇을 | 왜 |
|---|---|
| 노무사용 문서의 «사후관리 계약 구성(비용)» 표, 질문지의 수수료 질문 | 보내 주신 문서에도 "공개 사이트에는 넣지 않습니다"라고 적혀 있어서 |
| 사람 이름, «지점원1~7» 호칭 | 공개 사이트에는 사람 이름을 쓰지 않는 규칙 |

## 확인 부탁드릴 것

- [ ] 고친 문장이 보내 주신 뜻과 맞는지 (특히 "상여·성과급은 기금으로 줄 수 없음"을 얼마나 강하게 쓸지)
- [ ] 병의원 갈래를 «새 복지 재원형»으로 바꾼 것이 괜찮은지
- [ ] 고용장려금 금액·요건 표가 2026 기준과 맞는지
- [ ] 노무사용 문서를 지점원도 보는 사이트에 둘지, 따로 둘지
- [ ] 업체 분석 도구에서 «내 자격 = 노무사»로 바꿔 본 멘트가 실제 쓰시는 말과 맞는지
- [ ] 노무 허브 시안의 계산기 가정값(4대보험 부담률 등)이 맞는지

⚠ 세무 처리(출연금 손금, 유증 상속세, 장려금 수령분 처리)는 세무사 검토 사항입니다.
