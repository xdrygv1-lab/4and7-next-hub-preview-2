## 3. 이번에 넣지 않은 것 (확인 뒤 다음 단계)

| 자료 | 넣지 않은 이유 |
|---|---|
| 업체 분석 도구의 «노무사» 분기, 노무 신호 체크박스 | 도구 화면을 바꾸는 큰 작업이라, 문구를 먼저 확인받은 뒤 넣으려고 합니다 |
| 사근복 출연·사용 한도 계산기, 적합도 진단 | 4대보험 부담률 등 가정값을 먼저 확인받아야 합니다 |
| 노무사의 첫 미팅 (AP 15단계 노무사판) | 실제 방식이 아니라 AI가 바꿔 쓴 초안이라고 적혀 있어서, 직접 쓰시는 방식을 듣고 넣으려고 합니다 |
| 사례 수집 질문지, 기획안, 학습 노트 | 팀 내부 작업 자료라 공개 사이트에는 넣지 않았습니다 |
| 임원퇴직금 한도 배수 | 세무사 확인 사항이라 이번 범위에서 뺐습니다 |

## 4. 확인 부탁드릴 것

- [ ] 고친 문장이 보내 주신 뜻과 맞는지 (특히 "상여·성과급은 기금으로 줄 수 없음"을 얼마나 강하게 쓸지)
- [ ] 병의원 갈래를 «새 복지 재원형»으로 바꾼 것이 괜찮은지
- [ ] 고용장려금 금액·요건 표가 2026 책자와 맞는지
- [ ] 노무사용 문서를 지점원도 보는 공개 사이트에 둘지, 따로 둘지
- [ ] 3번 표에서 다음에 먼저 넣고 싶은 것

⚠ 세무 처리(출연금 손금, 유증 상속세, 장려금 수령분 처리)는 세무사 검토 사항입니다.
