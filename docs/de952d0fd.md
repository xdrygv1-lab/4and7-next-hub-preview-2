# 사근복 공식 근거 요약 (2025 매뉴얼 · '25 질의회시)

> **한눈에** 사근복 문서들이 기대는 공식 근거입니다. 근로복지공단 «사내 및 공동근로복지기금 실무 매뉴얼»(2025)과 고용노동부 «'25 질의회시집»을 쪽수·회시 번호와 함께 정리했습니다. 다른 사근복 문서의 내용이 헷갈리면 여기서 근거를 확인하세요.

## 근로복지공단 「사내 및 공동근로복지기금 실무 매뉴얼」 (2025) ★

**한 줄 요약** 사내·공동근로복지기금의 설립, 기관, 출연, 사업과 재원, 수혜대상, 운용, 해산, 보고, 벌칙, 정부 지원제도를 담은 공식 실무 매뉴얼이며, 이 묶음의 사근복 내용은 모두 이 자료를 1순위 근거로 했습니다.

> 표기: 쪽수는 매뉴얼 본문 쪽 번호입니다. 기준일은 2025년판 (정확한 발행일은 표지에서 확인하지 못함 [확인필요]).
> 매뉴얼은 각 장에 고용노동부 질의회시를 함께 싣고 있어서, 회시 번호와 날짜도 같이 적었습니다.

### (1) 적용 법규 (10쪽)
근로복지기본법·시행령·시행규칙, 사내·공동근로복지기금 업무처리지침(고용노동부예규 제169조, 2020.2.11. 일부개정), 공동근로복지기금 지원사업 운영규정(고시 제2023-18호, 2023.5.10. 일부개정), 잔여재산의 근로복지진흥기금 귀속절차(2009), 우리사주 주식구입 지원 지침(2011), 사업합병 업무처리요령(2011), 운용 가이드라인(2021.3.4.)

### (2) 제도 비교와 혜택 (10~12쪽)
- 사내기금: 한 사업장 근로자 대상, 사업장 특성에 맞는 사업, 노사 합의 쉬움
- 공동기금: 여러 사업주가 함께 출연, 규모가 작은 사업장·원하청·중소기업 간, 복지 격차 완화
- 사내기금이 맞는 경우: 맞춤 기금 운영 / 실적이 좋아 복리후생비를 주고 싶지만 매년 정기 지급은 어려움 / 복지포인트를 주고 싶지만 세금이 부담
- 공동기금이 맞는 경우: 규모가 작아 단독 운영이 어려움 / 영세 협력업체와 장기 거래하는 대기업 / 같은 지역·업종 중소기업

| 대상 | 혜택 (11쪽) |
|---|---|
| 기업 | 출연금 **법인세법에 따라 손금 인정** / 대기업이 중소기업 기금에 출연 시 **출연금 10% 법인세 세액공제** / 협력중소기업 기금 출연금은 미환류소득 계산 시 차감 / 대기업 지원 시 동반성장지수 가점 |
| 근로자 | 기금에서 받은 **특정 금품 증여세 비과세** / 정관에 따라 무상·저리 대출 시 적정이자와의 차이가 **1,000만원 미만이면 증여세 비과세** |
| 기금법인 | 출연받은 재산 증여세 비과세 / **피상속인이 기금에 유증한 재산 상속세 비과세** / 고유목적사업준비금 손금산입 |

- 근로자 측 장점(14~15쪽): 장학금·생활안정자금 대부, 우리사주·주택자금으로 재산형성, **"기금에서 지급하는 금품은 임금이 아니므로 소득세와 4대보험 부과대상 아님"**
- 사용자 측 장점(15쪽): 출연액은 기부금으로 인정되어 손금(매뉴얼 표현 그대로), 경영 여건에 따라 출연액 조정, **실질적 임금 인상 없이 복지혜택 제공**
- 원청 기금이 협력업체·파견 근로자를 지원해도 **불법파견 판단요소가 아님** (12쪽)
- 문의: 제도·설립·운용 고용노동부, 지원금 근로복지공단, 과세 국세청 (전화번호는 옮기지 않음)

### (3) 설립 (14~30쪽)
- 설립 가능: 비영리법인, 외국계, 정부산하기관, 신설회사, 지자체, **개인사업자** 모두 가능. 사업장이 여럿이면 주사무소에 설립하고 분사무소 운영 (15쪽)
- **이익이 없어도 설립·출연 가능** (퇴직연금복지과-4166 2022.10.23., -1918 2020.4.28.) (16쪽)
- 절차 (17쪽)

| 단계 | 내용 | 기한 |
|---|---|---|
| 설립 합의 | 노사협의회 의결(근참법 제21조 제3호), 없으면 사업주 결정 | |
| 설립준비위원회 | 노사 **각 2명 이상 10명 이하** 동수 | 설립 후 기금협의회로 전환 |
| 준비위 개최 | 정관, 이사·감사 선임, 사업계획서, 출연안 의결 | |
| 설립인가 신청 | 주사무소 관할 지방고용노동관서 근로개선지도과(노사상생지원과) | |
| 인가증 교부 | 노동부 심사 | **20일 이내** |
| 설립등기 | 주사무소 관할 등기소, "기타 분류할 수 없는 특수법인" | 인가증 수령 후 **3주 이내** (넘기면 인가 취소 가능) |
| 사무 인수인계 | 준비위 → 이사 | 지체 없이 |
| 사업자등록·고유번호증 | 관할 세무서, 홈택스 "06. 기타단체" | 등기 후 **20일 이내** |
| 계좌 개설 → 출연금 납입 | 기금법인 명의 | |

- 정관 필수 기재사항 14개 (19~20쪽, 시행령 제31조 ①): 목적 / 명칭("○○사내근로복지기금" 외 불가) / 사무소 / 조성·관리·출연시기·회계 / 협의회·이사·감사 / 대표권 / 사업·수혜대상 / 선택적 복지 / 정관 변경 / 통합운영 / 부동산 / 회의 / 공개방법 / 해산
- 대부사업을 하려면 정관에 근거 규정을 미리 두고, 구체 조건은 협의회가 정한다고 명시 (20쪽)
- 인가 신청 서류: 신청서, 정관, 준비위원 재직증명, 출연확인서 또는 재산목록, 사업계획서, 예산서 (21쪽)
- 제3자 출연은 가능하나 **사업주가 기금을 설치한 뒤에만** (임금 68207-237, 1997) (21쪽)
- 노동부 심사 체크리스트 (23쪽): 준비위 구성, 서류, 정관 기재사항, 법령 저촉·분쟁 소지, 사회통념상 부당 규정
- 수익사업을 시작하면 2개월 안에 수익사업 개시신고, 고유번호증 반납 후 사업자등록 (30쪽)

### (4) 기관 (31~39쪽)
| 기관 | 구성 | 핵심 |
|---|---|---|
| 기금협의회 | 노사 각 2~10명 동수 | 최고 의결기관. 근로자위원은 직접·비밀·무기명 투표 (과반수 노조가 있으면 노조 대표와 노조가 선출한 사람). 사용자위원은 대표자 + 대표가 위촉한 사람 |
| 이사 | 노사 각 **3명 이내** 동수 | 협의회 위원과 겸임 가능. 연임·해임 **3주 내 등기** |
| 감사 | 노사 각 **1명** | 협의회 위원·이사와 **겸임 불가** |

- 위원·이사·감사는 **비상근·무보수**, 직무를 이유로 한 불이익 금지, 기금 업무 시간은 근로시간으로 봄 (31쪽)
- 근로자위원은 재직 근로자만 (해고 다툼 중인 사람 불가, 노사협력복지과-2369 2004) (32쪽)
- 대표이사가 사업의 대표자라면 사용자위원에 포함되어야 함 (퇴직연금복지과-3806 2021) (32쪽)
- **주식만 가진 창업자·자녀는 사용자위원 불가** (퇴직연금복지과-4832 2021) (33쪽)
- 정관상 각 3명인데 직원이 5명뿐인 경우: 원칙적으로 무효, 예외적으로 운영하되 정족수는 지켜야 함 (퇴직연금복지과-2221 2019) (33쪽)
- 결원은 30일 안 보충 (33쪽)
- 의결: 노사 각 과반수 출석, 출석 **2/3 이상** 찬성. 소집 7일 전 통보. 회의록 **10년** 보관 (35쪽)
- 협의회 의결을 사업주가 번복·반대할 수 없음 (34쪽)
- **출연하지 않는 것도 협의회 의결로** (미조직근로자지원과-290 2024.8.14.) (34쪽)
- 근로자측 이사가 회사 임원이 되면 근로자대표 자격 상실, 대표이사가 반드시 기금 이사일 필요는 없음 (퇴직연금복지과-1705 2020) (36쪽)
- 이사·감사 임기를 "퇴직 시까지"로 정할 수 없음 (퇴직연금복지과-70 2019) (38쪽)
- 사용자측 이사·감사는 해당 사업의 사용자여야 함 (퇴직연금복지과-887 2024.2.26.) (38쪽)
- 이사가 사업범위·운용방법 위반, 불필요한 부동산 소유, 비밀누설, 자기거래 → 1년 이하 징역 또는 1천만원 이하 벌금 (38쪽)

### (5) 출연 (40~41쪽)
- 최초 출연: **직전 사업연도 법인세·소득세 차감 전 순이익의 5%** 기준, 준비위가 협의 결정. **5%는 적정선일 뿐, 낮추거나 초과 가능하며 초과해도 전액 손금 인정** (40쪽)
- 세전순이익: 법인은 기업회계기준 결산재무제표, 개인은 소득세 확정신고서. 결산이 늦으면 가결산서 기준 가능
- 출연 시기: 협의회 결정 후 **30일 이내**에 시기를 정해 통보. 일시·분할 모두 가능
- 출연 가능 재산: 현금, 유가증권, 업무상 필요한 부동산, 정관에 정한 재산 → "사실상 어떠한 재산이라도". **자사주식, 타사 상장주식, 어음, 직원 주택대출채권도 가능** (21쪽)
- 업무용(사무실, 구판장, 기숙사, 보육시설, 복지관, 콘도)이 아닌 부동산은 **1년 이내** 운용방법으로 전환
- **차입 채무가 있는 재산은 출연 불가**
- 잉여금은 기금에 전입하거나 고유목적사업준비금으로 계상. 근로복지기본법상 준비금 사용 기한 없음 (퇴직연금복지과-719 2019) (41쪽)

### (6) 사업과 재원 (42~62쪽) ★
**원칙 (43쪽)**: 근로자 전체 혜택, 저소득 우대 / 수익금으로 사업이 원칙, 기본재산·차입금 사용 불가(예외 있음) / **사업주가 법령·단체협약 등에 따라 지급할 의무가 있는 것은 기금 사업이 될 수 없음** / 시행세칙도 정관 부속서류라 인가 필요 (퇴직연금복지과-317 2008)

**재원과 사용 한도 (42쪽 표)**

| 구분 | 한도 | 요건 |
|---|---|---|
| 수익금 | 전액 | 원칙 |
| 해당 연도 출연금 | **50%** | 그해 출연이 있을 것 |
| 같은 출연금 | **80%** | ① 선택적 복지 ② 협력업체 근로자에 출연금의 10% 초과 20% 이하 사용 ③ **중소기업** |
| 같은 출연금 | **90%** | 협력업체 근로자에 출연금의 20% 초과 사용 |
| 자본금 초과액 | 기본재산이 회사 **자본금의 50%를 초과하는 금액** | 자본금 있는 사업만 |
| 5년 단위 | 기본재산 총액의 **20~30%** | 1인당 기본재산 200만원 이상 + 협력업체 근로자 1인당 수혜액이 소속 근로자의 25% 이상(25~35% 미만 → 20%, 35~50% 미만 → 25%, 50% 이상 → 30%) |
| 대부사업 | 기본재산 제한 없음 | 적정 규모 |

- 50% 사용 체크리스트(51쪽): 그해 출연 있음 / 제62조 ①의 사업 / 정관에 기본재산 사용 조항 / 협의회 결의 → 이월하려면 결산에서 고유목적사업준비금 계상
- 80% 체크리스트(51쪽), 자본금 초과액 체크리스트(52쪽), 5년 30% 체크리스트(52~54쪽)
- "5년마다"는 5년에 한 번만 정할 수 있다는 뜻 (54쪽)
- 정관에 "정관에 없는 사항은 근로복지기본법령에 따른다"는 준용 규정이 있으면 **정관 변경 없이** 기본재산 사용 가능 (54쪽)
- 공동기금 지원에 쓰면 그 지원액의 50%를 자체 사업에 추가 사용 (54~55쪽)

**목적사업 허용 여부 (44~45쪽 표)** (노무사 컨설팅의 핵심 표)

| ✅ 허용 | ❌ 불허 |
|---|---|
| 무주택 근로자 주택구입·임차자금 지원·대부 (유주택자는 정관에 엄격한 기준) | 전 근로자 **일률** 주택자금 명목 금품 |
| 저소득 근로자 생활안정자금 대부 (자격요건 심사) | 자격과 무관한 전 근로자 대부 / **지원금을 받은 기금의 대부사업** |
| 근로자·자녀 장학금·입학금 | 직원 아닌 불우이웃 장학금 |
| 재난구호금 (천재지변·사고) | 회사가 지급 의무 있는 재난구호금 |
| EAP 비용, 보육료, 법정 외 추가 보육시설 | |

## 「'25 사내 및 공동근로복지기금 질의회시집」 (고용노동부, '25.3월까지 회시) ★

**한 줄 요약** 기금 설립·수혜·기관·운영·출연·기본재산·목적사업·운용·해산에 관한 고용노동부 질의회시를 9개 장으로 모은 525쪽 자료입니다.

### 제목만 본 주요 회시 (목차, 본문 미확인)
- 1장: 1개 회사에 2개 기금 설립, 공공기관 자회사, 개인사업자의 공동기금, 지자체 기금
- 2장: 기간제·단시간 차등, 채무불이행 근로자 수혜 중단, 원청 의존도에 따른 공동기금 차등, 100% 자회사, 인력파견회사, 계약직 제외, 특정지역 근로자
- 4장: 기존 복지 중단·감축 판단, 자사 제품 이용, 선지급 후 정산, 중복수혜, 사업장 복지 통합, 취업규칙 변경 후 통합 운영
- 5장: 단체협약상 출연의무, 출연 강제, **조건부 출연 (1)(2)**, 주식 출연 (1)~(4), 제3자 출연, 부동산 출연, 출연 중단 결정
- 6장: 기본재산 사용 (1)~(4), 협력업체 수혜 산정, 5년 도과 후 재산처리, 주식출연 평가액만큼 사용 가능 여부
- 7장: 휴가비, 선택적 복지 최소금액, 청년내일채움공제, 정년퇴직 임박자·정년퇴직 축하금, 퇴직자 포인트, 노조원 한정, IRP 부담금, 다자녀 지원, 보증제도, 비혼 축하금, 차량구입 지원, 통신비, **건강보험료 근로자 부담분**, 기금 인건비, 협의회 위원 포상금, 개인연금, 식비, 주거지원, 자격증 차등, 추첨 방식, 명절효도비와 불이익변경
- 8장: 상각형 조건부자본증권, 주식 구입, 주식 장기보유, 대부 대손처리, 주식·펀드 투자, 자회사 주식 취득, 고유목적사업준비금 회계처리·이월, ETF, 회사채
- 9장: 해산 시 잔여재산 귀속, 폐업 10년 경과 사업장, 출연금 사용 후 해산
