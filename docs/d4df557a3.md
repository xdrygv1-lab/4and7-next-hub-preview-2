## 1. 한눈에 보는 제도

- **개념:** 사업주가 이익 일부를 출연해 **회사와 독립된 비영리법인**(기금법인)을 세우고, 그 기금으로 근로자 복지사업을 하는 제도. 설립은 의무가 아니라 임의.
- **누가 만들 수 있나:** 모든 사업장. 개인사업자, 신설회사, 외국계, 비영리법인, 지자체, 법무법인도 가능.
- **근거:** 근로복지기본법·시행령·시행규칙, 사내·공동근로복지기금 업무처리지침(고용노동부예규), 공동근로복지기금 지원사업 운영규정(고시 2023-18), 운용 가이드라인(2021.3.4.)

### 세제 혜택 (2025 매뉴얼 기준)

| 대상 | 혜택 |
|---|---|
| 회사 | 출연금 **법인세 손금 인정**. 5% 기준을 **초과해도 전액 손금** |
| 대기업 → 중소기업 기금 출연 | 출연금의 **10% 세액공제**, 미환류소득 차감, 동반성장지수 가점 |
| 근로자 | 기금에서 받는 금품은 **임금이 아니므로 소득세·4대보험 부과 대상 아님**. 특정 금품(장학금, 주택보조 등)은 **증여세 비과세**. 무상·저리 대부 이익이 1,000만원 미만이면 증여세 비과세 |
| 기금법인 | 출연받은 재산 증여세 비과세. 고유목적사업준비금 손금산입. 기금에 **유증한 재산은 상속세 비과세** |

> ⚠ 근로자 증여세 비과세는 **"특정 금품"**에만 해당됩니다(상증법 시행령 제35조 ④: 재난구호금·의료비, 학자금·장학금, 사회통념상 기념품·축하금·부의금, 무주택자 85㎡ 이하 주택 취득가 5%·전세가 10% 이내 보조). 그 밖의 지급 항목의 과세 처리는 **세무사 확인 필요**.

## 2. 설립 절차 (총 약 1~2개월)

| 순서 | 내용 | 기한·요건 |
|---|---|---|
| ① 설립 합의 | 노사협의회 의결 (없으면 사업주 결정) | 근참법 제21조 |
| ② 설립준비위원회 | 노사 **각 2~10명 동수** | 설립 후 기금협의회로 전환 |
| ③ 준비위 개최 | 정관, 이사·감사 선임, 사업계획서·예산서, 출연(안) 의결 | 최초 정관은 위원 전원 서명·날인 |
| ④ 설립인가 신청 | 주사무소 관할 지방고용노동관서 | 신청서, 정관, 위원 재직증명, 출연확인서(재산목록), 사업계획서·예산서 |
| ⑤ 인가증 수령 | 노동부 심사 | **20일 이내** |
| ⑥ 설립등기 | 주사무소 관할 등기소, "기타 특수법인" | 인가 후 **3주 이내** (넘기면 인가 취소 가능) |
| ⑦ 사무 인수인계 | 준비위 → 이사 | 지체 없이 |
| ⑧ 사업자등록·고유번호증 | 관할 세무서·홈택스 ("기타단체") | 등기 후 **20일 이내** |
| ⑨ 계좌 개설 → 출연금 납입 | 기금법인 명의 | 출연 후 기본재산 변경 **3주 내 보고** |

**정관 필수 기재 14개:** 목적 / 명칭("○○사내근로복지기금" 외 불가) / 사무소 / 조성·관리·출연시기·회계 / 협의회·이사·감사 / 대표권 / 사업 및 수혜대상 / 선택적 복지 / 정관 변경 / 통합운영 / 부동산 소유 / 회의 / 공개방법 / 해산
- 대부사업을 하려면 정관에 **근거 규정을 미리** 두어야 함
- 시행세칙도 정관 부속서류라 **인가를 받아야** 효력 있음
- 정관 끝에 "정관에 없는 사항은 근로복지기본법령에 따른다"는 준용 규정을 두면, 나중에 기본재산 사용 등에서 **정관 변경 없이** 처리 가능 → 처음부터 넣어 두기

## 3. 기관 구성 (소규모 사업장 최소 인원 계산)

| 기관 | 구성 | 핵심 |
|---|---|---|
| **기금협의회** (최고 의결기관) | 노사 **각 2~10명 동수** | 근로자위원은 직접·비밀·무기명 투표 (과반수 노조가 있으면 노조가 선출). 사용자위원은 **대표 + 대표가 위촉한 사람**. 주식만 가진 창업자·자녀는 사용자위원 불가 |
| **이사** | 노사 **각 3명 이내 동수** | 협의회 위원과 겸임 가능. 연임·해임은 3주 내 등기 |
| **감사** | 노사 **각 1명** | 협의회 위원·이사와 **겸임 불가** |

- 개의: 노사 각 과반수 출석 / 의결: 출석 **2/3 이상** 찬성 / 소집 7일 전 통보 / 회의록 **10년** 보관
- 위원·이사·감사는 비상근·무보수, 기금 업무 시간은 근로시간으로 인정, 직무를 이유로 한 불이익 처우 금지
- 근로자측 이사가 회사 임원이 되면 근로자대표 자격 상실
- 이사·감사 임기를 "퇴직 시까지"로 정하는 것은 불가

> **최소 인원(실무 계산):** 근로자측 = 협의회 위원 2명(이사 겸임) + 감사 1명 = **3명**, 사용자측도 같은 방식으로 **3명** → 대략 **노사 합계 6명**이 필요합니다. 직원 5명 사업장 사례에서 노동부는 "정관상 정원에 못 미치면 원칙적으로 무효이나, 구성이 불가능하면 예외적으로 운영하되 정족수는 지켜야 한다"고 회시했습니다(2019).

## 4. 출연

- **기준:** 직전 사업연도 세전순이익의 **5%**. 다만 "적정선"일 뿐이라 **줄이거나 늘릴 수 있고, 이익이 없어도 출연 가능** (신설회사도 설립 가능)
- **시기:** 협의회가 출연을 결정하면 30일 안에 출연 시기를 통보. 일시·분할 모두 가능
- **수년치 일시 출연:** 5년분을 한 번에 출연해 여러 해에 걸쳐 써도 됨 (2022 회시)
- **출연할 수 있는 재산:** 현금, 유가증권, **자사주식·비상장주식**, 어음, 기존 직원 주택대출 채권, 업무용 부동산 등 사실상 모든 재산
 - 업무용이 아닌 부동산은 **1년 안에** 법정 운용 방법으로 전환
 - **차입 채무가 딸린 재산은 출연 불가**
- **제3자 출연:** 가능하지만 사업주가 기금을 만든 **뒤에만**. 근로자 출연도 회시 사례 있음
- **반환:** 출연금은 원칙적으로 돌려받을 수 없음 (착오로 더 낸 부분만 부당이득 반환 가능)
- **출연 중단:** 경영이 어려울 때 출연하지 않는 것도 **협의회 의결**로 결정 (2024 회시)

## 5. 기금 사업과 쓸 수 있는 돈 ★ 컨설팅 핵심

### 5-1. 원칙
- 원칙은 **운용 수익금**으로만 사업. 기본재산(원금)과 차입금은 사용 불가
- 근로자 **전체**가 혜택을 받게 하되 **저소득 근로자 우대**
- **사용자가 법령·단체협약·취업규칙·근로계약상 줄 의무가 있는 것은 기금 사업이 될 수 없음**

### 5-2. 기본재산(원금) 예외 사용 한도

| 구분 | 한도 | 요건 |
|---|---|---|
| 일반 | 해당 연도 출연금의 **50%** | 그해 출연이 있을 것 + 정관 조항 + 협의회 결의 |
| **중소기업** / 선택적 복지 / 협력업체 근로자에게 출연금 10~20% 사용 | **80%** | 위 요건 + 해당 사유 |
| 협력업체에 출연금 20% 초과 사용 | **90%** | |
| 자본금 초과액 | 기본재산이 회사 자본금의 **50%를 넘는 부분** | **자본금 있는 사업만** (개인사업자 적용 불가, 2020 회시) |
| 5년 단위 사용 | 기본재산 총액의 **20~30%** | 1인당 기본재산 200만원 이상 + 협력업체 근로자 수혜 비율 25% 이상 + 5년에 한 번 결정 |
| 공동기금 지원 | 기본재산 총액 범위 | 지원액의 50%까지 자체 사업에 추가 사용 |

- 이월해서 쓰려면 결산 때 **고유목적사업준비금**으로 계상. 사용 기한은 근로복지기본법상 없음 (세법상 5년 규정은 세무사 확인)
- **대부사업**은 기본재산으로 제한 없이 할 수 있음. 단, **정부 지원금을 받은 기금은 대부 불가**

### 5-3. 되는 것 / 안 되는 것 (매뉴얼·회시 종합)

| ✅ 가능 (정관에 근거 필요) | ❌ 불가 |
|---|---|
| 무주택자 주택구입·임차 보조·대부 (유주택자는 엄격한 기준이 있어야 가능) | 전 직원에게 **일률적으로** 주택자금·휴가비·월동비·체력단련비·유류비 명목 현금 지급 |
| 근로자·자녀 장학금·학자금, 자녀 학원비·유치원비 | 사용자가 줄 의무가 있는 **퇴직금**, 명예퇴직 위로금, 퇴직자 전별금 |
| 재난구호금, 경조비, 의료비·건강진단비(가족 포함 가능) | **성과급·격려금·포상금, 우수사원 포상** (업무·실적 관련 금품) |
| 선택적 복지포인트 (용도 제한형) | **4대보험 사용자 부담분**, 업무 출장비·연수비, 업무용 비품 |
| 체육·문화 관람료, 동호회비, 근로자의 날 행사 | 특정 직급·부서·노조원만 대상으로 하는 지원 |
| 명절·창립기념 선물, 상품권, 생일·출산 축하금 | 일반 아파트·빌라를 사서 기숙사로 쓰는 것, 호텔·요트 |
| **직장인 단체보험(보장성·저축성) 가입 지원, 전 직원 개인보험 가입 지원** | **특정 직원·부서만 보장성(종신)보험** 가입 |
| 개인연금·IRP 근로자 부담금 지원, 대출이자 지원 | 사업주가 설치 의무가 있는 직장어린이집 운영 |
| 우리사주조합을 통한 구입 지원·대부 | 조합을 거치지 않는 자사주 매입 지원 |
| 기숙사(법정 요건 충족), 구내식당, 사내카페, 콘도, 골프회원권(전 직원용) | 근로자가 아닌 사람(불우이웃, 친목회)에 대한 기부 |

### 5-4. "임금 대체" 판단 기준 (가장 중요)
노동부 회시(퇴직연금복지과-341, 2021)는 다음을 종합해서 판단합니다.
1. **근로 제공의 대가인가**
2. 여행·건강·문화·체육 등 **실제 사용 용도에 따라** 지급되는가
3. 주택자금·장학금·경조사비처럼 **정해진 요건에 따라** 지급되는가

→ **"성과 보상 성격으로 용도와 관계없이 전 직원에게 일률적으로 현금 지급"하면 임금 대체**로 봅니다.
→ 반대로 용도가 정해진 분기별 복지포인트(근로와 무관하게 배정)는 임금 대체가 아니라고 봤습니다(대법원 2016다48785 참조).

### 5-5. 기존 복지를 기금으로 옮길 때
- 단체협약·취업규칙·내부규정에 이미 있는 복지는 **원칙적으로 기금으로 지급 불가**
- 단, **노사 합의로 단체협약·규정을 고쳐** "재원을 기금으로 할 수 있다"고 명시하고, 정관에도 근거를 두면 가능 (2022 회시)
- ⚠ **기금을 만들었다는 이유로 기존 복지제도를 중단·감축하면 사용자 형사처벌** (1년 이하 징역 또는 1천만원 이하 벌금)

## 7. 기금 운용 (돈을 굴리는 방법)

**법정 방법만 가능 (근로복지기본법 제63조):**
1. 금융회사 예입·금전신탁 (MMT 가능)
2. 투자신탁 수익증권 (ELS·ELB 등 가능, 원금 훼손이 적은 상품 권장)
3. 국가·지자체·금융회사가 발행하거나 보증하는 유가증권 (일반 기업 회사채는 불가, 2024 회시)
4. 출연받은 자사주가 있을 때, 기본재산의 20% 범위에서 유상증자 참여
5. 투자회사 주식, 부동산투자회사(REITs) 주식

- **저축보험:** "금융회사 등에의 예입"에 해당하면 운용 방법으로 가능 (2020 회시, 상품별 확인 필요)
- **비상장주식:** 출연받은 비상장주식은 안정성·유동성이 확보되는 한 **계속 보유 가능** (2019 해석 변경)
- 신종자본증권은 부적절
- **의사결정:** 예금·국공채·A+ 이상 채권은 이사회 / 금전신탁·수익증권·A 이하 채권·투자회사 주식은 협의회 / 기금의 20% 이상 또는 10억 이상이면 외부 투자자문 필요
- **부동산:** 원칙적으로 소유 금지. 사무실, 기숙사, 구판장, 보육시설, 콘도, 복지회관만 예외

## 10. 해산 (출구가 거의 없음)

- **해산 사유는 4가지뿐:** ① 사업 폐지 ② 기금법인 합병 ③ 분할·분할합병 ④ 공동기금 참여
- 경영난, 목적 달성, 근로자 과반수 동의, 재산 소진은 해산 사유가 **아님** (정관에 넣어도 무효)
- 협동조합 전환이나 사업 양도로 대부분의 직원이 나가도 "사업 폐지"가 아님
- **잔여재산 순서:** 미지급 임금·퇴직금 → 남은 재산의 50%까지 근로자 생활안정자금 → 정관이 지정한 자(유사 목적 단체, 다른 기금법인 가능) → 없으면 근로복지진흥기금
- **회사나 대표에게 돌아오는 길은 없음**

## 11. 정부 지원금

| 유형 | 지원 |
|---|---|
| 대기업 기금이 협력업체 근로자 복지에 지출 | 지출액의 50%, 연 최대 2억 |
| 대기업이 출연한 중소기업 기금 | 출연받은 금액의 50%, 연 최대 2억 |
| **공동기금** (중소기업이 포함된 둘 이상 기업) | 출연금의 **100%** 범위, 참여 규모에 따라 **2억(3년)~20억(5년)**. 지역·산업 단위(50개소·1,500인 이상)는 7년 30억 |
| 대기업이 중소 공동기금에 출연 | 매년 2억~10억 |
| 지자체가 중소 공동기금에 출연 | 3년간 매년 최대 6억 |
| **지원 불가** | 참여 기업끼리 **법인세법상 특수관계인** (가족회사 등), 공공기관 기금 |

- 심사위원회 점수에 따라 지원율 100/75/50%/배제
- 지원금을 받은 기금은 **대부사업 금지**

## 13. 컨설팅에 바로 쓰는 포인트

**이런 회사에 맞음**
- 이익이 꾸준하고 **새로 복지를 늘리려는** 회사 (기존 복지를 대체하려는 회사가 아님)
- 무주택 직원, 자녀 학자금, 경조·의료 수요가 많은 회사
- 중소기업 → 그해 출연금의 **80%**까지 바로 사용 가능
- 협력업체·파견 근로자가 많은 원청 → 지원금과 기본재산 사용 한도 확대
- 관계없는 중소기업 여러 곳 → **공동기금**으로 정부 지원 최대 출연금의 100%

**처음부터 분명히 말해야 하는 것**
1. 출연금은 **돌려받을 수 없고**, 기금은 **사실상 해산이 안 된다**
2. **대표 본인은 혜택을 받을 수 없다**
3. **성과급·상여를 기금으로 바꾸는 것은 안 된다**
4. 기존 복지를 줄이고 기금으로 돌리면 **형사처벌** 대상이다
5. 해마다 **보고·등기·회의록 관리**가 필요하다 → 노무사 사후관리 계약의 명분

**첫 미팅 질문 (허브 문서 보완)**
- "올해 새로 늘리고 싶은 복지가 있으세요? 주택, 학자금, 의료비 중에 직원들이 제일 원하는 게 뭘까요?"
- "지금 취업규칙이나 단체협약에 들어가 있는 복지는 어떤 게 있으세요?" (대체 불가 항목 확인)
- "협력업체나 파견 직원이 함께 일하고 있나요?" (지원금, 사용 한도 확대)
- "회사에 자사주나 정리하고 싶은 비상장주식이 있으세요?" (주식 출연)

**첫 요청 자료**
3개년 재무제표, 상시근로자 명부(고용 형태별), 취업규칙·단체협약·복지 규정, 현행 복지 지출 내역(계정별원장), 노사협의회 구성 현황, 자기주식 현황, 정관
