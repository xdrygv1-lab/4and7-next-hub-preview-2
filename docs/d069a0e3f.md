# 10월 토요특강 정리: 세무사의 실전 영업·자산 컨설팅

> **한눈에** 리치디바인 10월 토요특강(4개 강의)에서 바로 쓸 기법만 모았습니다. 고객 확보(SNS·카톡), 20분 판서 상담, 무료 영업권 평가 명분, 법인 자금 인출 5경로, 연령대별 상담, 거절 대응까지. 세무 수치와 전략은 강의 사례라 **세무사 검토 사항**입니다.

## 1. 세일즈 관점 (강의 ①③)

- 7단계(프로스펙팅 → TA → 어프로치 → 팩트파인딩 → 프레젠테이션 → 클로징 → 소개요청)를 외우지 말고 **단계마다 무엇을 고민할지** 따진다. 프로스펙팅은 "프레젠테이션까지 갈 수 있는 고객이 누구인가"부터.
- 세일즈 정의: 고객의 필요를 파악해 **고객이 원하는 것과 내가 제안할 수 있는 것을 연결**. 설명보다 상대가 받아들일 수 있는 수준으로.
- 대표(세무사)의 역할은 일을 직접 처리하기보다 **일할 기회를 만드는 것**. 기장 실무는 빨리 채용해서 맡긴다.
- 롤모델은 "보험 잘하는 전문직"이 아니라 **최상위(TOT) 설계사**. 전문직도 그 수준의 영업 훈련·활동 관리가 필요(아침 브리핑·저녁 결과 보고).
- 사람을 만나 계약까지 약 **10시간**. 영업은 원래 비효율, 효율화는 시스템에 맡긴다. 전환율 20%면 20곳 얻으려면 100명을 만나야 함 → 모수를 계속 늘린다.
- **분기 사이클**: 4분기 = 프로스펙팅(모수 확보) → 1분기 = 어프로치 대상 선별 → 2~3분기 = 집중 영업. 3분기는 법인전환 이슈가 적어 **기존 고객 관리**.
- **카톡 3색 분류**: 보라 = 법인전환 제안 중, 초록 = 수임 완료, 빨강 = 미수임·잠재.
- **TA는 일정 잡기가 아니다**: 약 1시간(줌 권장) 동안 성향 파악, 미팅 아젠다 설계, 차별점 각인. TL 단계에서 기장 고객과 보험·컨설팅 고객을 미리 나눈다.
- **RP**는 질문 준비가 아니라 **거절에 대한 재반박** 훈련. "Sell me this pen": 스펙 나열이 아니라 니즈와 위기감.

## 2. 20분 판서 상담 (강의 ③)

종이·칠판·태블릿에 점선을 긋고 소득·지출·여유자금을 그리며 진행.
1. 왼쪽에 **월 매출 + 3대 고정비(인건비·임차료·카드 사용액)**를 적는다.
2. **신고서 경비율 vs 실제 경비율** 대조. 예: 실제 70%인데 신고 90% → 가공경비 = 세무조사 위험 + 실제 영업이익 왜곡.
3. "이거 안 하면 내가 손해" 인식 → 고객이 먼저 **"어떻게 해야 하나요?"**를 묻게 만든다.
4. 끝은 군더더기 없이 가입 의사만 확인할 수 있는 단순한 플랜.
5. **5·7·10년 잉여금 누적 그래프**로 청산 시 세금 부담을 보여 준다.

## 3. "무료 기업가치(영업권) 평가" 명분 (강의 ③)

- 법인전환을 직접 권하지 않고 **무료 영업권 평가**를 제안 → 거절 장벽이 낮다.
- 이 과정에서 **사업자등록증과 직전 3개년 재무제표를 자연스럽게** 받는다.
- 당기순이익이 높고 자산이 적을수록 영업권 평가에 유리. 협력 감정평가사 프로세스 필요(기준금액 3억 이하 간이 평가 언급, 확인 필요).
- 영업권은 법인 자금 인출 경로 중 **초기 일시금**(기타소득) 수단이기도 함.

→ **우리 도구 반영**: KoData 자동 연동이 막힌 지금, "3년 재무제표를 받는 명분"으로 그대로 쓸 수 있다.

## 4. 자산·재무 프레임 (강의 ③)

- **축구 포지션 자산 배분**: 골키퍼(현금성, 최소 10%) · 수비수(채권·보험, 20~30%) · 미드필더(ETF·커버드콜·배당) · 공격수(주식). 공격만 하면 후반에 실점.
- **"제투부 · 세상 · 은의"**: 불리기(재무관리·투자설계·부동산) / 넘기기(세금설계·상속증여 가업승계) / 지키기(은퇴·위험관리: 대표 유고, 자금경색, 지분분쟁).
- **인생 5대 주기자금**: 생활, 주택, 자녀 양육·교육, 결혼·전세 지원, 노후 → "기간과 금액"으로 질문.
- 은퇴 소비 곡선: 초기 10년 상승 → 중간 안정 → 말기 10년 간병비 급증. 통계 화법: 노후 준비 충분 19% 미만, 실제 은퇴가 희망보다 평균 9년 빠름, 준비 시작 평균 48세. "자산 인출은 축적보다 어려운 금융 문제".
- 연금 3층(국민·퇴직·사적), 한국은 보험 가입률은 높고 사적연금은 낮다. 자산이 부동산 → 금융으로 갈수록 비과세·분리과세 설명 기회.

## 5. 법인 자금 인출과 적립 (강의 ③④)

- **법인 자금 유출 5대 경로**: ① 영업권(초기 일시금) ② 급여(단계적 인상, 퇴직 전 3년 급여가 퇴직금 한도 기반) ③ 배당(주주 구성, 정기·차등) ④ 퇴직금(임원 규정) ⑤ 자기주식·이익소각(의제배당).
- 인출 예시: 연 생활비 7~8천만원 → **배당 우선, 부족분 급여, 퇴직금은 장기 인출 수단**. 주주 1인당 배당 2천만원(금융소득 종합과세 기준선) 활용 언급.
- 시뮬레이션 예시: 7년간 22.2억 인출 → 세금·4대보험 뒤 실질 약 15억(64~66%), 10년 기준 65~75%. **가정에 따른 예시**, 전제 명시.
- **잉여금의 25~50%(권장 30%)**를 적립 플랜으로 전환 → 7년 분할 적립 + 은퇴 공백기 인출.
- **퍼센트 제안**: 매출의 5~10% 수준으로 부담을 상대화(다른 현장 기준 "연 보험료 ≤ 매출 2%"와 차이 있음 → 고객 현금흐름으로 판단).
- **계약 분할(쪼개기)**: 월 1,000만원이면 200~300만원 단위 여러 계약으로 → 필요할 때 나눠 해지해 환급금(익금) 시점 분산, 대표 급여·퇴직금 비용과 시점 매칭. **세무사 검토 필수**, 과세이연 효과는 사실관계에 따라 다름.
- **DBR(납입 대비 사망보험금)**: 40~50대 약 3배, 고령 약 1.7배 → "보험료는 사라지는 비용이 아니라 나중에 돌아오는 비용". 100% 주식형 변액정기, 달러 경영인정기 연계.

## 6. 연령대별 대표 상담 (강의 ④)

| 연령 | 주제 | 질문·제안 방향 |
|---|---|---|
| 30대 | 성장기 재투자 vs 개인 자산(주택·차량) 우선순위, **60~70대 부모의 승계·상속**과 결합 | 기업보험 + 개인 종신 연계 |
| 40대 | 확장기, 교육비·주택 지출, 사업 위험이 개인 자산으로 번질 위험 | 사업·생활·노후 자금 분리, 잉여금 출구(배당·가족법인), 누진세율 구간이면 법인전환 검토(절세 보장 아님), 15~20년 잉여금·세금 판서 |
| 50대 | 매각·승계, 은퇴 현금흐름, 법인 자산의 개인화, 건강(암·간병) | 공격형 → 안정형, 부동산 일부 현금흐름화, 건강 보장 함께. 자금 악화 시 보험부터 깨지 않도록 다른 자산 활용 설명 |
| 60대 | 법인 자산 인출, 실제 퇴직, 상속세 재원 | 가입 제한 가능 → 남은 기간 맞춤 보장 중심 |

## 7. 법인 보험 실무 (강의 ④)

- **비용처리 보수적 접근**: 보험사에서 사업비·위험보험료·적립보험료 구분 자료를 받아 **사업비 + 위험보험료만 비용**. 종신보험은 통상 20~30% 언급(상품·판단별 상이). 해약환급금 기준 비용처리는 이후 과세·환류·민원 위험. **담당 세무사·회계사와 사전 합의**.
- 단기납 종신: 납입 종료 시 환급률 100% 안팎, 10년+1일 후 약 124.8%(강의 장표 예시, 상품·가입형별로 다름) → 비용처리 이슈.
- 법인 계약 심사: 피보험자 업무 관련성(원천징수·급여 내역, 등기임원), 타사 가입액 포함 소득 대비 한도, **신설법인 2년 제한**(상품별 확인).
- **대표 퇴직 후에도 비용처리 계속하는 상황은 위험** → 임원·주주 지위와 퇴직 시점 점검.
- 변액정기는 **개인사업자에게도** 제안 가능성(자격 요건 확인).
- 원화보증·추가납입: 환율 상승 시 초과 출금 부담 완화(10·20·30% 설정 사례).
- 감액완납: 보장 줄이고 납입 완료 처리. 연금·종신 전환과 과세 시점 차이 → 전문가 확인.
- 달러 설명법: 위기 때 자산 가치·유동성(물 부족 비유), 분할 매입 평균단가, 상품권 vs 현금(유동성). 상품보다 **자산 구성과 외화 관심부터** 확인.

## 8. 상담 진행·거절 대응 (강의 ③④)

- 첫 상담은 **팩트파인딩 중심**. 구체 인출 설계에 들어가면 정리하고 **다음 미팅에서 제안**. 다음 미팅을 2~3주 뒤로 미루면 안 됨: **팩트파인딩 뒤 주말을 넘기면 계약률이 떨어진다**.
- 장표 의존보다 **말로 목적과 구조를 이해**시킨다. 프레젠테이션 기준 질문: "왜 금융상품인가".
- 커피챗 전 **사전 설문**으로 상황·관심사 파악.
- 거절 대응(19가지 중 소개된 것):
 - "배우자와 상의할게요" → 장단점을 먼저 같이 정리해 보자고 질문, 필요하면 **배우자 동반 미팅**.
 - 선택지가 많아 망설임 → **원화·달러 등 두 가지로 단순화**.
 - 결정 미룸 → 늦어질 때의 영향을 사실과 선택지로(압박 X).
 - 비용 부담 → **월 단위로 쪼개서**, 가입 필요성과 미가입 위험을 균형 있게.
 - **미팅 직전 취소** → "이미 근처에 와 있습니다. 결정하는 자리가 아니라 설명만 20분 보시죠."(근접성 화법)
- **실질 의사결정권자(배우자·부모)** 공략: 그 사람의 관심사(예: 취미)를 공유하며 신뢰. 가족 중 전문 지식이 있는 사람은 우군으로.
- 계약 전 보험금·환급률·사망보장 기능을 분명히 설명. 계약 후 **적립 현황·회계처리 분기 보고**, 채권·ELS 등 부가 정보 제공.
- 오픈채팅에서 경쟁 전문가가 이의 제기 → 공개 논쟁 피하고 개인 대화로.

## 9. 고객 확보·브랜딩 (강의 ①②)

- 구매 결정의 95%는 타인의 평가·추천 영향. **"무엇을 보여줄까"가 아니라 "어떻게 보일까"**를 설계.
- **SNS의 목적 = 이미 만난 사람이 나를 다시 확인(검증)하는 창구**. 명함만 쌓이고 전환이 안 되는 문제를 해결.
 - 블로그: 유입보다 **검색했을 때 확인되는 장치**, 고객 후기·감사 메시지 노출.
 - 인스타그램: 정보 글 X, **강의·외부 활동·상담 장면**으로 권위. 숫자(조회수·팔로워) 자체가 권위.
 - 유튜브: 불특정 다수 X, **기존 고객이 소개할 사람에게 보낼 영상**.
 - 스레드: 글 중심·독백형, 공감하는 사람을 모으는 곳(반말 대신 독백).
 - **카카오톡 = 끝판왕**: 명함 주고받은 사람은 이미 잠재고객. **단체방보다 1:1**, 카테고리 관리(약 1,600명), 멀티프로필(고객용에는 보험 활동을 처음부터 드러내지 않음), 프로필 변경으로 상단 노출.
- **스레드 운영법**(강의 ②):
 - 피드·프로필·게시물을 **한 타깃**(예: 학원장·병원장)으로 맞춰 알고리즘 신호를 준다. 개인 관심사는 다른 계정.
 - 새 계정은 처음 1주 좋아요·팔로우로 신호 → 게시량을 5 → 10 → 20개로. 처음부터 대량 게시하면 정지 위험.
 - 하루 20개 약 15분, **예약 발행(25개)**, 글 재고 100개를 나만의 오픈채팅방에 저장.
 - 게시 시간은 업종 생활 패턴에 맞춤(학원장 오전·저녁, 병원장 점심·퇴근 후).
 - "세무사입니다"보다 **그 업종을 안다**는 인상(학원가·학군·교재·시험기간 등).
 - 사진·영상·설문 기능 활용, 이모지·AI 티 나는 문장·타 전문가 비방 금지.
 - **10개 중 8개는 후킹 소재, 2개는 핵심 서비스**(법인전환·경비·자금 인출).
 - 최종 목적지는 **카카오톡 오픈채팅**(스레드 댓글에 링크, 인스타 댓글 링크는 안 눌림). 방에서 공개 답변(허락 후)·후기로 검증 → 1:1 상담 → 오프라인.
 - DM을 기다리지 말고 "딱 10명만" 같은 희소성 문구로 **고객이 직접 행동**하게. 갑작스러운 줌 세미나 공지(빈자리 드러내지 않기).
 - 인사이트로 반응 좋은 글(4대보험·건보료, "월매출 3천이면 대형 학원?") 분석 → AI로 같은 주제 10개 재가공.
 - 계약은 만난 지 **수개월 뒤**(9월 만남 → 다음 해 10월 계약). 스레드는 장기 신뢰 채널.
 - 세무 정보는 단정 금지("무조건 절세 0원" X), 개정안을 확정처럼 쓴 실수 사례.
- **강연을 만들기**: 1:1보다 강사-수강생 구도가 권위. 직접 모임을 만들기보다 **사람 많은 모임 운영진에게 강의 제안**, 공유오피스 대표에게 제안. 5명이어도 됨.
- **소개 요청**: 바로 요청하면 부담 → 꾸준히 챙겨 고객이 고마움을 느낀 뒤, **소개받은 고객이 맡기면 기존 고객에게 혜택**처럼 체감되는 보상과 함께.
- **상담 녹음 → 요약 보고서**: 허락 받고 녹음 → 텍스트 → 보고서를 고객에게 보내며 다음 미팅 잡기.
- 맞춤 상담자료: 표지에 **상대 회사 이름**, 기장 미이행·가산세·특례·비용처리 등 대중 관심 주제. 명함 대신 자료를 건넨다.
