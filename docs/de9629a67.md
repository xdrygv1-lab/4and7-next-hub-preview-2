# 고용장려금, 지점원이 먼저 알아보는 법 (2026)

> **한눈에** 세무사·회계사·FP 지점원이 거래처에서 고용장려금 신호를 알아보고 노무사에게 넘기는 법입니다. 지점원은 금액을 약속하지 않습니다. **신호를 보고, 질문 세 개를 하고, "받을 수 있는지 노무사와 확인해 드릴게요"로 연결**하는 데까지가 지점원의 일입니다.
>
> 기준: 고용노동부 「2026 고용장려금 지원제도」 (2026년 1월 기준). `[사례 대기]`는 실제 사례를 받은 뒤 채웁니다.

---

## 1. 지점원이 알아 둘 다섯 줄

1. 고용장려금은 **채용, 출산·육아, 근무시간 조정, 정년 이후 고용, 휴업·휴직**에 고용보험이 주는 돈입니다.
2. 중소기업은 거의 **우선지원대상기업**이라 대부분 대상이 됩니다.
3. **신청 기한**을 넘기거나, 받는 동안 **다른 직원을 감원**하면 못 받거나 환수됩니다.
4. **대표 가족**(배우자·직계 존비속)과 **월 보수 124만원 미만** 직원은 대부분 제외됩니다.
5. 일부 장려금은 **먼저 사업참여 신청**을 해서 승인받아야 합니다. 그래서 일이 벌어지기 **전에** 노무사를 부르는 게 좋습니다.

---

## 2. 이런 신호가 보이면 노무사를 부르세요

| # | 신호 | 어디서 보이나 | 연결되는 장려금 (2026) |
|---|---|---|---|
| 1 | **사람을 새로 뽑는다** ("사람 구하고 있어요", 채용 공고) | 대화, 결산 시 인건비 증가 계획 | 청년일자리도약(청년 정규직, 월 최대 60만원 1년), 고용촉진(취업 취약계층) |
| 2 | **출산·육아휴직자가 있거나 생긴다** ("직원이 임신했어요", "육아휴직 들어가요") | 대화, 4대보험 변동 | 육아휴직 지원금(월 30만원, 특례 첫 3개월 100만원), 대체인력(월 최대 140만원), 업무분담(월 최대 60만원) |
| 3 | **정년이 가까운 직원이 있다** ("곧 정년인데 계속 쓰고 싶어요") | 직원 연령, 대화 | 고령자 계속고용(분기 90만원, 비수도권 120만원, 3년) |
| 4 | **계약직·파견을 오래 쓴다** (6개월 이상) | 근로자 명부, 외주비 | 정규직 전환(월 40~60만원 1년, 5~30인 미만) |
| 5 | **매출이 크게 줄었다** (직전 6개월 평균보다 15% 이상) | 손익계산서, 부가세 신고 | 고용유지지원금(휴업·휴직수당의 2/3, 1일 68,100원) |

**보조 신호**
- 직원이 근로시간을 줄이고 싶어 한다 (가족돌봄·건강·학업·은퇴준비) → 워라밸일자리(월 30+20만원)
- 재택·시차출퇴근을 하고 있거나 하고 싶다 → 유연근무 장려금(월 20~30만원, 육아기 2배)
- 주4.5일제를 검토한다 (20인 이상) → 워라밸+4.5 프로젝트
- 직장어린이집이 있거나 만들려고 한다
- 비수도권(서울·인천·경기 밖) 사업장 → 계속고용·청년 장기근속인센티브가 더 큼

**이럴 땐 넘기기 전에 기대를 낮추세요**
- 뽑으려는 사람이 대표 가족이다
- 공공기관, 유흥·사행 업종, 임금체불·중대재해로 명단이 공개된 사업장이다
- 이미 채용하고 1년이 지났다 (신청 기간 경과 가능성)

## 3. 지점원이 던질 질문 세 개

| 질문 | 이런 답이 나오면 | 다음 |
|---|---|---|
| **Q1.** "올해 사람 새로 뽑으실 계획 있으세요? 혹시 청년이나 오래 쉬셨던 분도 생각하세요?" | 채용 계획이 있음 | 신호 강함. **채용 전에** 노무사 연결 |
| | 이미 최근에 뽑았음 | 채용일을 메모 (신청 기한 확인용) |
| **Q2.** "직원분 중에 출산휴가나 육아휴직 쓰시는 분, 또는 정년 앞둔 분 계세요?" | 있음 | 신호 강함. 대체인력·계속고용 가능성 |
| **Q3.** "받을 수 있는 장려금이 있는지 노무사님이랑 한번 확인해 보실래요? 직원 명부만 있으면 됩니다." | "좋아요" | 동행 일정 확정 (5장) |
| | "보험 얘기죠?" | "아니요, 장려금 확인만 해 드립니다." |

## 4. 하지 말아야 할 말

| ❌ 하지 말 말 | 왜 안 되나 | ✅ 대신 이렇게 |
|---|---|---|
| "무조건 ○○만원 받으실 수 있어요" | 요건·제외 대상·예산 소진·심사에 따라 달라짐 | "받으실 수 있는지 노무사님과 확인해 드릴게요" |
| "일단 뽑고 나중에 신청하시면 돼요" | 공모형은 사전 신청이 필요하고, 신청 기한이 있음 | "뽑기 전에 한번 보는 게 가장 좋습니다" |
| "가족을 직원으로 올리면 장려금 받아요" | 대표 배우자·직계 존비속은 대부분 제외, 허위 신청은 부정수급 | (권하지 않음) |
| "장려금 받는 동안에도 정리할 사람은 정리하셔도 돼요" | 고용조정 제한 기간에 감원하면 지급 제한·환수 | "받는 기간에는 권고사직을 조심하셔야 합니다" |
| "서류만 맞추면 돼요" | 부정수급은 반환 + 2~5배 추가징수 + 형사처벌 | "실제 상황 그대로 신청합니다" |
| "보험 들어 주시면 장려금 챙겨 드릴게요" | 대가형 영업, 팀 원칙 위반 | (말하지 않음) |

## 5. 노무사에게 넘기는 법

### 5-1. 대표님께 하는 연결 멘트
> "대표님, 이번에 뽑으시는 분(또는 육아휴직 쓰시는 분) 조건이면 받을 수 있는 장려금이 있을 수 있어요. 신청 기한이 있어서 제가 함께 일하는 노무사님과 빨리 확인해 보겠습니다. 다음 주 화요일 오후와 목요일 오전 중에 언제가 편하세요?"

### 5-2. 노무사에게 보내는 요청 (카톡용)
```
[4&7 고용장려금 확인 요청]
· 업종 / 지역 (수도권·비수도권):
· 직원 수 (고용보험 가입자 기준, 대략):
· 보인 신호: (2장 번호, 예: 1, 2)
· 채용 계획: 인원 / 나이대 / 정규직 여부 / 채용 예정일 (이미 뽑았으면 채용일)
· 출산·육아휴직: 사용자 수, 시작 예정일, 대체인력 계획
· 정년 도래자: 인원, 정년 시기
· 비정규직: 인원, 근속 기간
· 매출 감소: 있음/없음 (대략 %)
· 미팅 일정: ○월 ○일 ○시
※ 회사명·대표 이름·직원 이름·연락처·주민번호는 단톡방에 쓰지 마세요.
```

### 5-3. 미리 받아 두면 좋은 자료
| 자료 | 용도 |
|---|---|
| 고용보험 가입자 명부 (또는 직원 수) | 우선지원대상기업 여부, 지원 인원 한도 (보통 피보험자의 30%, 10명 미만은 3명) |
| 근로계약서, 취업규칙 | 정규직 여부, 계속고용·근로시간 단축 제도 명시 여부 |
| 임금대장 | 월 보수 124만원 기준, 임금 인상 여부 |
| 출산·육아휴직 사용 현황 | 출산육아기 장려금 |
| 최근 매출 자료 | 고용유지지원금 요건 |

### 5-4. 관할 고용센터
- 장려금 신청·문의는 **사업장 소재지 관할 고용센터(기업지원팀)** 가 맡습니다. 청년일자리도약은 고용24에서 관할 **운영기관**을 골라 신청합니다.
- 연락처는 노무사가 「2026 고용장려금 지원제도」 88~94쪽 또는 고용24 서식자료실의 「고용센터 연락처」 파일로 확인합니다. (이 문서에는 연락처를 옮기지 않았습니다.)
