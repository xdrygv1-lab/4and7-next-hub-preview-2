# 변액리치정기 MAVERICK (변액 경영인정기)

## 지금 확인된 조건 (2026-11 기준)

> **한눈에** 정기보험에 30종 펀드(주식형 100% 가능)를 얹은 변액 정기. 신설법인·개인도 가입 가능

| 항목 | 내용 |
|---|---|
| 가입나이 (만기별) | 60세 만기 15~40(간편 30~40) / 70세 15~50(30~50) / 80세 15~60(30~60) / 90세 15~70(30~75) |
| 가입금액 | 일반 1,000만원~50억 / 간편 1,000만원~20억 (100만원 단위) |
| 보험기간·납입 | 60·70·80·90세 만기, 전기납, 월납 |
| 사망보험금 | 가입금액·적립액 × 105%·기납입보험료 중 큰 금액. 보증비용 연 가입금액의 0.011% |
| 플러스보험기간 | 만기 때 적립액이 남으면 15년 더 보장. 예시(40세 남 1억 월 113,600원, 3.75% 가정): 91세부터 사망보험금 1억 1,430만원, 환급률 90세 157.1% → 100세 122.3% → 105세 0% |
| 최소보험료 | 월 8만원(주계약+특약 합산). 미달 시 3대 진단특약 기간납으로 채움. 11/04 교육은 «월 5만원 검토 중» |
| 펀드 | 30종: 국내주식 4, 해외주식 5, 테마 6, 자산배분 7, 국내채권 2, 해외채권 5, 골드 1 |
| 옵션 | 추가납입 기본보험료 총액 100%(사업비 없음), 중도인출(회당 해약환급금 50%, 총 기납입 100%까지), **계약대출 불가**, 조기계약전환 36회+사유, 전환 7년(적립형·원화연금·달러연금·달러저축·종신) |
| 전환 금액 조건 | 적립형: 적립액 ≥ 기납입 70%와 100만원 중 큰 금액 / 원화연금: 해약환급금 1,000만원 이상 / 달러연금: $1만 이상(7년 전에는 환급금이 기납입 초과이면서 $9만 이상) / 달러저축: 특약 부가 시 주계약 해약환급금 90% 이내 / 종신: 전부 해지 |

### 판매 포인트
- "이 돈 언제 꺼내실 겁니까?" 15~20년 뒤면 펀드형으로
- 같은 사망보장에 보험료가 낮음 (50세 남 30억 월 459만원 vs 달러경정 300만달러 월 1,635만원)
- «변액은 손해» 반론: 인정 → 재정의(저축 아닌 정기보험, 사망보험금은 가입금액 보증) → 증거 순서로. «중간에 깨면 손해는 그때나 지금이나 같다»는 꼭 말함
- 추가납입 100%를 쓰면 10년 환급률 83.1% → 102.1%

### 주의
- 원금손실 가능, 해약환급금 보증 없음(-1% 가정 시 30년 49%), 유지보너스 없음, 예금자보호는 최저사망보험금·특약만 1인 1억(법인계약 제외)
- 비용처리: 는 «가능(세법 요건 충족 시)», 표준교안은 언급 없음. 세무사 검토 사항, 단정 금지
- 안정성을 원하는 고객은 달러경영인정기가 맞음. 기존 경정 해지 후 갈아타기, 기존 계약 중도인출·대출로 보험료 내기 유도 금지
- 상품안내장 폴더본은 협회 심의필 번호가 빈칸인 본

### 확인 필요
- 최소보험료 8만 vs 5만
- 중도인출 표현: 팩트체크 «회당 해약환급금 50%, 연 4회» vs 응대 스크립트 «기납입보험료 100%까지»(총한도)
- 추가납입 최소금액 (팩트체크 10만원 / 1만원)
- 비용처리 표현
- 상품안내장 협회 심의필 확정본
