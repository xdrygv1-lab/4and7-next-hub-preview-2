# 사근복, 지점원이 먼저 알아보는 법

> **한눈에** 세무사·회계사·FP 지점원이 거래처에서 사내근로복지기금 신호를 알아보고, 노무사에게 넘기기까지의 내용입니다. 지점원은 제도를 설명하지 않습니다. **신호를 보고, 질문 세 개를 하고, 노무사 동행 약속을 잡는 것**까지가 지점원의 일입니다.
>
> 2026-11-04 · 상태: 초안 (실제 사례 반영 전, `[사례 대기]` 표시 부분은 사례를 받은 뒤 채웁니다)

---

## 1. 지점원이 알아 둘 다섯 줄

1. 회사가 이익 일부를 출연해 **회사와 별개인 기금법인**을 만들고, 그 돈으로 직원 복지를 합니다.
2. 기금에서 받는 복지는 임금이 아니라서 직원에게 **소득세·4대보험이 붙지 않고**, 회사 출연금은 **손금**입니다.
3. **새로 늘리는 복지**에만 씁니다. 상여·성과급을 바꿔 담거나 기존 복지를 옮기는 제도가 아닙니다.
4. **대표 본인은 혜택을 받을 수 없고**, 출연한 돈은 돌려받을 수 없습니다.
5. 설립보다 **해마다 관리**가 중요해서 노무사가 처음부터 끝까지 같이 갑니다.

---

## 2. 이런 신호가 보이면 노무사를 부르세요

결산서, 계정별원장, 대표님과의 대화에서 볼 수 있는 신호입니다. **두 개 이상**이면 노무사 동행을 제안할 만합니다.

| # | 신호 | 어디서 보이나 | 왜 사근복 신호인가 |
|---|---|---|---|
| 1 | **세전순이익이 2~3년 꾸준히 난다** (대략 수억 원대) | 손익계산서 | 출연 기준이 직전 연도 세전순이익의 5%. 이익이 꾸준해야 해마다 복지 재원이 생김 |
| 2 | **복리후생비가 크거나 늘고 있다** (명절선물, 경조비, 의료비, 회식 외 지원) | 복리후생비 계정별원장 | 앞으로 **새로 늘릴** 복지를 기금으로 하면 효과가 큼 |
| 3 | **직원에게 빌려준 돈이 있다** (주택자금·생활자금 대여) | 주임종 단기대여금, 종업원 대여금 계정 | 기금의 대부사업으로 할 수 있는 영역. 회사가 직접 빌려주는 부담을 덜 수 있음 |
| 4 | **대표님이 직원 문제를 먼저 꺼낸다** ("사람이 자꾸 나가요", "직원들한테 뭘 더 해 줄 수 없나") | 대화 | 급여 말고 직원을 붙잡을 카드를 찾는 중 |
| 5 | **직원이 10명 이상이다** (최소 대표 포함 6명) | 4대보험 가입자 명부, 급여대장 | 기금 기관을 꾸리려면 노사 각 3명이 필요 |

**보조 신호** (있으면 더 좋음)
- 자사주를 보유하고 있다 (재무상태표 자기주식) → 주식 출연형 검토
- 협력업체·파견 직원과 함께 일한다 → 사용 한도 확대, 정부 지원금
- 중소기업이다 → 그해 출연금의 80%를 바로 사용 가능

**이럴 땐 넘기지 마세요** (지금은 맞지 않음)
- 최근 손실이 나거나 현금흐름이 빠듯하다
- 대표 포함 6명이 안 된다 (→ 공동기금은 노무사와 따로 상의)
- 대표님 관심이 오직 "본인 절세"에 있다

## 3. 지점원이 던질 질문 세 개

노무 지식 없이도 할 수 있는 질문입니다. 답을 받아 두면 노무사가 바로 이어받습니다.

| 질문 | 이런 답이 나오면 | 다음 |
|---|---|---|
| **Q1.** "직원분들께 올해 새로 해 주고 싶은 게 있으세요? 주택, 자녀 학비, 의료비 같은 거요." | 구체적인 항목을 말함 | 신호 강함. Q2로 |
| | "해 주고 싶은데 돈이 부담돼서…" | 신호 강함. "같은 돈으로 더 많이 주는 방법"을 노무사가 보여 줄 수 있다고 연결 |
| | "지금도 충분히 해 줘요" | 현재 복지가 취업규칙에 있는지 노무사가 확인해야 함. 넘기되 기대치를 낮춤 |
| **Q2.** "직원분들이 몇 분이고, 그만두는 분이 많은 편이에요?" | 10명 이상, 이직이 잦음 | 신호 강함 |
| | 5명 이하 | 사내기금은 어려움. 공동기금 가능성만 메모 |
| **Q3.** "혹시 직원분들 복지를 어떻게 하면 좋을지 노무사랑 한번 이야기해 보실래요? 제가 같이 모시고 오겠습니다." | "그래요" | 동행 일정 확정 (5장 양식) |
| | "보험 얘기죠?" | "아니요, 오늘은 직원 복지 이야기만 합니다." (6장 원칙) |

## 4. 하지 말아야 할 말

| ❌ 하지 말 말 | 왜 안 되나 | ✅ 대신 이렇게 |
|---|---|---|
| "상여나 성과급을 기금으로 주시면 세금이 줄어요" | 실적에 따른 상여·성과급·격려금은 기금으로 줄 수 없다는 노동부 회시가 여러 번 있음 | "새로 늘리실 복지가 있으면, 같은 돈이 직원에게 더 많이 가는 방법이 있어요" |
| "지금 주시는 복지를 기금으로 돌리시면 돼요" | 기존 복지를 줄이고 기금으로 대체하면 **사용자 형사처벌** (1년 이하 징역 또는 1천만원 이하 벌금) | "지금 복지는 그대로 두고, 앞으로 늘리실 부분을 보는 거예요" |
| "대표님도 혜택 받으실 수 있어요" | 대표·업무집행 임원은 수혜 대상이 아님 | "직원 복지 제도라 대표님은 받으실 수 없어요. 대표님 쪽은 따로 보겠습니다" |
| "기금 만들면서 보험도 같이 하시죠" | 노무 용역의 대가로 보험을 요구하면 신뢰가 무너지고, 기금 안에 대표 보험은 불가 | (보험 이야기를 하지 않음) |
| "나중에 필요하면 다시 빼 쓰시면 돼요" | 출연금은 돌려받을 수 없고, 기금은 사업 폐지 전에는 해산되지 않음 | "한 번 넣은 돈은 직원 복지로만 쓰여요. 그래서 감당되는 만큼만 시작합니다" |
| "무조건 절세돼요", "세무조사 걱정 없어요" | 직원 수령분의 세무 처리는 항목마다 다름 | "세무 처리는 세무사님과 노무사가 같이 확인합니다" |
| 제도 세부 설명 (출연률, 사용 한도, 설립 절차) | 지점원이 설명하면 틀리기 쉽고, 노무사 미팅의 명분이 사라짐 | "자세한 건 노무사가 대표님 회사 숫자로 계산해서 보여 드릴 거예요" |

## 5. 노무사에게 넘기는 법

### 5-1. 대표님께 하는 연결 멘트
> "대표님, 직원 복지를 같은 돈으로 더 크게 해 주는 제도가 있는데, 이건 노무사 영역이라 제가 함께 일하는 노무사님을 모시고 오겠습니다. 대표님 회사 숫자로 계산해서 보여 드릴 거예요. 다음 주 화요일 오후와 목요일 오전 중에 언제가 편하세요?"

- 날짜는 **이지선다**로 묻고, 그 자리에서 확정합니다.
- "노무사님한테 연락드리라고 할게요"는 하지 않습니다. 지점원이 **동행**하는 것이 원칙입니다.

### 5-2. 노무사에게 보내는 동행 요청 (카톡용)
```
[4&7 사근복 동행 요청]
· 업종 / 지역:
· 법인·개인 / 직원 수:
· 세전순이익 (최근 1~3년, 대략):
· 보인 신호: (2장 번호로, 예: 1, 2, 4)
· Q1 답 (새로 하고 싶은 복지):
· Q2 답 (직원 수·이직):
· 대표님 관심도: 높음 / 보통 / 낮음
· 미팅 일정: ○월 ○일 ○시, 장소
· 나와 대표님 관계: 기장 ○년 / 소개 / 초면
· 조심할 점: (예: 보험 경계, 다른 컨설턴트 다녀감)
※ 회사명·대표 이름·연락처·사업자번호는 단톡방에 쓰지 마세요.
```

### 5-3. 미리 받아 두면 좋은 자료
| 자료 | 지점원이 받기 쉬운가 | 용도 |
|---|---|---|
| 최근 3년 재무제표 | ✅ (기장 거래처면 이미 있음) | 출연 가능액 계산 |
| 복리후생비 계정별원장 | ✅ | 현재 복지 지출 확인 |
| 4대보험 가입자 명부 또는 직원 수 | ✅ | 기관 구성 가능 여부 |
| 취업규칙·단체협약·복지 규정 | ⚠ 노무사가 받는 게 자연스러움 | 기금으로 옮길 수 없는 복지 확인 |
| 정관, 주주명부 (자사주 있으면) | ⚠ | 주식 출연형 검토 |

| 설립 | | ✅ 정관·인가·등기 | 사업자등록·회계 지원 |

**보험 연결 원칙 (팀 확정)**
- 노무 용역(기금 설립)의 대가로 보험을 요구하지 않습니다.
- 기금 안에 대표 보험을 넣지 않습니다. 대표 보장·퇴직금 재원은 회사 차원에서 따로 봅니다.
- 기금 목적사업으로 **전 직원** 단체보험 가입 지원은 가능하지만, 이것도 노무사가 설계할 때 직원 복지 항목으로 다룹니다.

## 8. 지점원이 자주 하는 오해

**"세무사인 내가 설명해도 되지 않나?"**
신호를 알아보고 연결하는 데까지가 좋습니다. 기존 복지와 취업규칙 검토, 기관 구성, 인가는 노무 영역이고, 여기서 틀리면 대표님이 처벌받을 수 있습니다.

**"절세 상품으로 소개하면 되지 않나?"**
사근복은 직원 복지 제도입니다. 절세로만 소개하면 "상여를 기금으로" 같은 위험한 설계로 흐르기 쉽습니다.

**"작은 회사는 안 되나?"**
대표 포함 6명이 안 되면 사내기금은 어렵습니다. 관계없는 회사 여러 곳이 함께 만드는 공동기금은 정부가 출연금의 최대 100%를 지원하니, 노무사와 상의하세요.

**"한 번 만들면 끝인가?"**
아닙니다. 해마다 노동부 보고, 협의회 회의, 등기, 서류 공개가 필요합니다. 그래서 노무사의 사후관리가 함께 갑니다. 지점원에게는 해마다 거래처를 방문할 명분이 됩니다.
