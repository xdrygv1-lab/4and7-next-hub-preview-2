# 지점원 핵심요약 (출력용)

> **한눈에** 노세대 트랙용 A4 2~3쪽 요약입니다. 큰 그림, 꼭 알아야 할 20개, 청약 가는 날 챙길 것만 담았습니다.

## 1쪽. 큰 그림
- 본업으로 대표님의 문제를 먼저 풀고, 해결 수단 중 하나로 보험을 제안합니다. 보험은 **마지막 한 칸**입니다.
- 주로 다루는 보험: **경영인정기보험**(대표 유고 대비, 퇴직금 재원 설계), **종신보험**(상속세 재원, 가족 보장, 목적자금)
- 영업 순서: 발굴(PS) → 전화약속(TA) → 첫 미팅(AP) → 제안(PC) → 계약(C) → 소개·사후관리
- 첫 미팅 목표는 **다음 약속과 소개**. 상품 이름은 꺼내지 않고, 제안 전 **선심사**부터.

## 2쪽. 꼭 알아야 할 20개

| 번호 | 용어 | 한 줄 |
|---|---|---|
| 1 | 계약자·피보험자·수익자 | 내는 사람(법인)·보장 대상(대표)·받는 사람(법인) |
| 2 | 서면동의 | 대표 자필 서면동의 없으면 **계약 무효** |
| 3 | 해약환급금 | 중간 해지 때 돌려받는 돈, 낸 돈보다 적을 수 있음 |
| 4 | 환급률 | 돌려받는 돈 ÷ 낸 돈. 100% 미만이면 원금 손실 |
| 5 | 저해약환급금형 | 경정기 **3년 전 0%, 3~5년 50%** |
| 6 | 체증형 | 경정기 **10년 후 매년 10%** 증가 |
| 7 | 감액완납 | 납입 멈추고 보장 줄여 유지, **5년** 후 |
| 8 | 종신전환 | **7년** 이상 유지 후, 기존 해지·그때 나이 요율 적용 |
| 9 | 보험계약대출 | **10년** 이내, 대표 **75세** 이하 |
| 10 | 달러보험 | 환율 하락 시 원화 손실 가능, 장점만 말하면 불완전판매 |
| 11 | 고지의무 | **청약서에 글로** 적어야 효력 |
| 12 | 일반 vs 간편 | 간편은 약 **20%** 비쌈, 2년 내 질병 사망 시 **50%** |
| 13 | 재정심사 | 고지소득은 보험료·직업과 맞아야 함 |
| 14 | 상품 한도 ≠ 심사 한도 | 실제 금액은 재정심사로 결정 |
| 15 | 세무 처리 | 세무 처리(비용처리·손금·익금 등)는 세무사 검토 사항 |
| 16 | 세금 | 없어지는 게 아니라 **뒤로 미뤄지는 것**(세무사 검토 사항) |
| 17 | 세무 문구 | 단정하지 않고 세무사 검토로 안내 |
| 18 | 대표 명의 이전 | 평가 기준 없음, **확정 제안 금지** |
| 20 | 하지 말 것 | 수익 약속, 가입 대가 현금, 컨설팅 대가로 묶기, 해지 전제 판매 |

## 3쪽. 청약 가는 날 챙길 것

**출발 전**
- [ ] 선심사 결과, 실제 가입설계서 출력
- [ ] 원수사 작성예시에 형광펜, 한 번 더 검증
- [ ] 보험료 출금일 확인

**대표님께 받을 것**
- [ ] 청약서 서명·법인인감 날인, 부속서류·주주명부 날인
- [ ] 법인인감증명서 원본
- [ ] 사업자등록증·법인등기부등본·법인통장·대표 신분증 사본

**함께 확인할 것**
- [ ] 5년 이내 암 진단, 2년 이내 수술·입원(청약서에 직접)
- [ ] 저해약 구간(3년 전 0%), 달러 상품이면 환율 위험
- [ ] 고객보관용 서류 전달, "보험사에서 확인 전화가 갑니다" 안내

**청약 후**
- [ ] 첫 출금 확인, 그 사이 안부 연락
- [ ] 증권은 방문 전달하며 보장 점검
- [ ] 청약철회: 증권 받은 날부터 **15일** 이내(청약일부터 **30일** 넘으면 불가), 상품마다 다를 수 있음

모르면: 지점장, 원수사 매니저

## 꼭 확인할 것
- [ ] 법인계약 서류 최종 목록을 보험사 기준으로 확인했다
- [ ] 세무 설명은 세무사 검토 사항으로 안내했다
- [ ] 청약철회 기간을 상품별로 확인했다
