# 주력상품 한눈에 비교

> **한눈에** 경영인정기보험 2종, 종신보험 4종, 변액 종신 1종, 출시 예정 변액 경정기까지 주력상품을 한 표로 비교했습니다. 내부 교육용이며, 고객에게 보여줄 수치는 반드시 가입설계서·상품설명서 기준입니다.

## 기능 비교

| 상품 | 전환·감액·대출 |
|---|---|
| 경정기(달러·원화) | 감액완납 **5년** 후, 종신전환 **7년** 이상, 연금전환 7년·환급금 1만달러(1,000만원) 이상, 조기전환 36회+사유, 대출 10년 내·75세 이하. 원화고정납은 달러형만 |
| 백만인 | 연금전환·달러저축전환 특약 자동부가, 사망보험금 유동화 |
| 3년내 | 납입면제(간편은 재해만), 간병선지급 |
| 모두의 달러 | 사망보험금유동화, 납입면제·페이백 특약 |
| 모두의상속 | 추가납입(완납 후, 총액 200%), 중도인출(36개월 후, 50% 이내 연 4회), 감액·대출 |

## 어떤 상품부터 볼까요

| 상황 | 먼저 볼 상품 | 근거 |
|---|---|---|
| 개인사업자·개인 | 경정기 아님 → 종신 쪽 | 세무 처리는 세무사 검토 사항 |
| 법인 대표 40대 | 달러 경정기 또는 원화 | 달러 40세 일반 10년 **94.9%**(1위와 0.9%p 차이), 원화는 보험료 최저 |
| 법인 대표 50~60대 초반 | 경정기 가능하나 환급률 하락 | 달러 10년: 50세 **93.3%**, 60세 **87.2%**. 100% 미만이 불만이면 백만인 단기납 또는 타사 원금형 비교 |
| 70세 이상 | 경정기 대신 종신·상속형 | 경정기 70세 10년: 달러 **62.7%**, 원화 **60.3%** |
| 신설법인 | 가입 가능 여부 원수사 확인 | (확인 필요) |
| 목적자금, 사망 니즈 작음 | 백만인 달러 7년납·5년납("7+3") | 40세 10년 **124.8%** |
| 환율이 싫은 목적자금 | 백만인 원화 | |
| 상속재원, 오래 내기 싫음 | 3년내고만족 | |
| 상속재원, 은퇴 시점 납입 종료 | 모두의 달러종신 | |
| 상속재원 + 추가납입 + 원금손실 감수 | 모두의상속종신 | |
| 고령·유병 간편 | 76~80세는 3년내 간편, 75세까지는 백만인·모두의상속 간편 | 간편은 2년 내 재해 외 사망 시 **50%** |
| 간편 vs 일반 | 일반심사 우선 | 간편은 약 **20%** 비싸고 10년 환급률 1%p 내외 낮음 |

⚠ 고객에게는 상품명보다 니즈 질문을 먼저 합니다. AP에서 상품명은 꺼내지 않습니다.

## 공통 주의
- ⚠ 변액은 수익률 변동·원금손실 가능, 법인 계약자·납부자면 **예금자보호 대상 아님**

- ⚠ 보험사 내부 교육용 자료는 고객에게 보여주지 않습니다. 고객 실명도 쓰지 않습니다.
