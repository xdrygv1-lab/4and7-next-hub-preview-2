# 설립 절차와 해마다 할 일

> **한눈에** 설립은 1~2개월이면 끝나지만, 기금은 사업을 폐지하기 전에는 해산되지 않습니다. 해마다 보고·등기·회의록 관리를 해야 하므로 **노무사 사후관리**가 꼭 필요한 제도입니다.

## 설립 순서

| 단계 | 할 일 | 기한·요건 |
|---|---|---|
| 1. 설립 합의 | 노사협의회 의결 (없으면 사업주 결정) | 근참법 제21조 |
| 2. 준비위원회 구성 | 노사 각 2~10명 동수 | 설립 후 기금협의회로 전환 |
| 3. 준비위원회 개최 | 정관, 이사·감사 선임, 사업계획서·예산서, 출연안 의결 | 최초 정관에 위원 전원 서명·날인 |
| 4. 설립인가 신청 | 주사무소 관할 지방고용노동관서 | 신청서, 정관, 위원 재직증명, 출연확인서, 사업계획서·예산서 |

| 7. 사무 인수인계 | 준비위원회 → 이사 | 지체 없이 |
| 8. 사업자등록·고유번호증 | 관할 세무서·홈택스 ("기타단체") | 등기 후 **20일 이내** |
| 9. 계좌 개설·출연 | 기금법인 명의 계좌 | 출연 후 기본재산 변경 **3주 내** 보고 |

## 기관 구성

| 기관 | 구성 | 주의 |
|---|---|---|
| 기금협의회 | 노사 각 2~10명 동수 | 근로자위원은 직접·비밀·무기명 투표. 사용자위원은 대표 + 대표가 위촉한 사람 |
| 이사 | 노사 각 3명 이내 동수 | 협의회 위원과 겸임 가능 |
| 감사 | 노사 각 1명 | 협의회 위원·이사와 **겸임 불가** |

- **최소 인원:** 협의회 2명(이사 겸임) + 감사 1명 → **노사 각 3명, 합계 6명**
- 의결: 노사 각 과반수 출석, 출석 2/3 이상 찬성. 소집 7일 전 통보
- 주식만 가진 창업자·자녀는 사용자위원이 될 수 없음 (회사 임직원이 아니면)
- 이사·감사 임기를 "퇴직 시까지"로 정하면 안 됨

## 정관에 꼭 넣을 것 (14개)
목적 / 명칭("○○사내근로복지기금") / 사무소 / 조성·관리·출연시기·회계 / 협의회·이사·감사 / 대표권 / 사업·수혜대상 / 선택적 복지 / 정관 변경 / 통합운영 / 부동산 / 회의 / 공개방법 / 해산

**실무 팁**
- 대부사업을 하려면 근거 규정을 처음부터
- 가족·유족 수혜를 하려면 정관에 명시
- "정관에 없는 사항은 근로복지기본법령에 따른다"는 준용 규정을 넣으면 나중에 정관 변경 없이 처리되는 경우가 생김
- 시행세칙도 정관 부속서류라 인가를 받아야 효력 있음
